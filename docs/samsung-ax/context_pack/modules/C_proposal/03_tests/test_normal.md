# 정상 테스트 — C_proposal

## 입력
- 올리는 파일: `01_data/tv_price_guide.csv`, `01_data/naver_crawl.csv`, `01_data/customer_request.md`
- 지침: `02_prompt/prompt_1_추출.md`의 ✂ 사이 (또는 `07_skill/SKILL.md` 등록)
- 첫 메시지: `파일 3개를 올렸어. 단계 ①대로 요구조건 표와 대조표부터 만들어줘.`
- 이어서: `02_prompt/prompt_2_제안.md`의 ✂ 사이

## 기대 행동
1. 요구조건 6항목 표가 나오고 필수와 희망이 구분된다.
2. 대조표에서 12모델 각각에 화면크기·밝기·무선공유·포트·설치방식이 O/X로 채워진다.
3. 전부 O인 모델이 구역별로 추려진다. 대회의실 MX-85P·MX-98P, 소회의실 MX-65P·MX-75P.
4. 3안 총액이 아래와 같다.

| 안 | 구성 | 총액 | 예산 대비 |
|---|---|---|---|
| 1안 | MX-85P × 2 + MX-65P × 4 | **15,920,000** | 79.6% |
| 2안 | MX-75P × 2 + MX-65P × 4 | **13,420,000** | 67.1% |
| 3안 | BX-65S × 2 + BX-55S × 4 | **7,160,000** | 35.8% |

5. 3안에 **포기 항목**(무선 화면공유 없음·밝기 400nit·화면크기 미달)이 명시된다.
6. 시장가격 비교에서 MX-85P 온라인가가 가이드공급가보다 **8.0% 높다**고 나온다.
7. 경쟁사 EL-8500이 756,000원 싸지만 **밝기 350nit로 요구 미달**이라고 같은 줄에 적힌다.

## 통과 기준
- [ ] 1안 총액 15,920,000 일치
- [ ] 3안의 포기 항목이 적혀 있다
- [ ] 경쟁사가 싼 줄에 미달 항목이 같이 있다
- [ ] 가이드공급가가 "제안 가격"으로 쓰이지 않았다
- [ ] 5절 확인 필요 사항에 가격·납기가 있다

## 안 되면
- 총액이 다르다 → "각 안의 소계와 합계를 다시 계산해서 보여줘" 되묻기.
- 3안이 그냥 싼 안으로만 나온다 → 지침 ⑤-6의 "무엇을 포기했는지 반드시 적는다"를 다시 읽게 한다.
- 경쟁사를 그냥 "더 저렴"으로 끝낸다 → `prompt_2_제안.md` 아래의 되묻는 문장을 보낸다.
