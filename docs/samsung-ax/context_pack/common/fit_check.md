# 적합성 체크 — 이 업무를 오늘 Agent로 만들어도 되는가

> 유진투자증권 과정의 「STEP 0 적합성 체크리스트 7항목」을 삼성 B2B 영업 환경에 맞게 옮겼습니다.
> 쓰는 곳: ① 사전과제 응답 필터링 ② 워크북 「내 업무로 전환하기」 ③ 7일 적용 계획 첫날

---

## 1. CANNOT 7항목 — 하나라도 해당하면 범위를 줄이거나 분리합니다

| # | 해당하면 오늘은 안 되는 것 | 삼성 환경에서의 근거 |
|---|---|---|
| ① | **ERP·SCM·CRM 등 사내 시스템과 자동 연동** | 9/9 확인 — 사내 데이터 연동은 현재 없음. 엑셀 등 로컬 파일을 올리는 수준 |
| ② | **고객 담당자 개인정보·계약 단가·미공개 실적**을 입력에 포함 | `security_rules.md` 업로드 금지 목록 |
| ③ | **별도 개발**(스크립트·API·크롤러 작성)이 필요 | 본 과정은 웹 ChatGPT·Gemini만 사용. 코덱스는 별도 차수 검토 중 |
| ④ | **사내 데이터 구조에 의존**(사내 DB 스키마, 코드 체계 조회) | 더미 데이터로 재현 불가 |
| ⑤ | **가격·납기·할인·계약 조건을 AI가 확정** | 사람 승인 지점. Agent는 초안·후보만 |
| ⑥ | **외부 인터넷이 막힌 환경**에서만 돌아가야 함 | 실습장은 외부 인터넷 가능. 현업 적용 시 확인 |
| ⑦ | **고객·파트너에게 직접 발송**(메일·문자·카톡 발신) | 초안 작성까지만. 발송은 사람 |

**도메인 전문가가 결과를 검수한다면 일부 관여는 괜찮습니다.** 관여해야 하는데 안 할 때가 문제입니다.

## 2. CAN — 오늘 만들 수 있는 것의 모양

| 조건 | 예 |
|---|---|
| 입력이 **파일**로 준비된다 | 판매 실적 엑셀, 가격 가이드, 뉴스 스크랩 CSV |
| 출력이 **초안·후보·표**다 | 제안 제품 3개 비교, 추천 TOP3, 영업기회 리스트 |
| 사람이 **마지막에 판단**한다 | 제안 여부, 가격, 파트너 논의 사항 확정 |
| 같은 일이 **반복**된다 | 월말 보고, 신규 수요처마다 제안, 권역 점검 |

삼성 확정 Agent 4개(A·B·C·D)는 모두 이 모양입니다.

---

## 3. 업무 유형 A~D — 내 업무는 어느 건인가

| 유형 | 이름 | 특징 | 삼성 Agent 대응 |
|---|---|---|---|
| **A** | 단발 처리 | 파일을 받아 한 번 처리하고 끝 | **C 제안자료** (요구조건 → 제안 3개), **D 데이터 분석** (버티컬 → 추천) |
| **B** | 정기 반복 루틴 | 매주·매월 같은 시점에 같은 형식으로 | **A·B Sensing** (권역·수요처 정기 점검) |
| **C** | 감시·알림 | 조건이 걸릴 때만 동작 | (오늘 범위 밖 — 사내 연동 필요) |
| **D** | 질문 답변 | 정해진 자료에 대해 묻고 답함 | (제품 스펙 Q&A로 확장 가능) |

유형을 정하면 **입력이 언제 들어오는지**와 **출력이 어디로 가는지**가 정해집니다. 지시문 ③입력 검사와 ⑤출력 형식이 여기서 나옵니다.

---

## 4. 좋은 과제 3원칙

| 원칙 | 내용 |
|---|---|
| **작은 성공 (5~10%)** | 전체 업무의 일부만 자동화합니다. "제안서 전체"가 아니라 "제안 제품 후보 3개 고르기" |
| **초안 수준** | 완벽하게 만들려 하지 않습니다. 교육 중 생각이 바뀝니다 |
| **내가 할 수 있는 쉬운 일** | 자주 해온 일을 고릅니다. 남의 일, 안 해본 일은 검수를 못 합니다 |

## 5. As-Is → To-Be 한 줄

전환 표를 채우기 전에 이 두 줄을 먼저 씁니다.

```
As-Is: 매번 ______를 손으로 ______해서 ______가 걸리고 형식이 들쭉날쭉하다
To-Be: AI가 ______를 받아 ______ 초안을 만들고, 사람은 ______만 검수·확정한다
```

예 (Agent D)
```
As-Is: 신규 수요처마다 과거 실적 엑셀을 열어 비슷한 업종을 손으로 찾느라 반나절이 걸린다
To-Be: AI가 실적 파일과 수요처 버티컬을 받아 추천 TOP3와 근거를 만들고, 사람은 제안 여부만 정한다
```

## 6. 판정표 (사전과제 필터링용)

| 항목 | 판정 |
|---|---|
| CANNOT 7항목 중 해당 | ☐ 없음 → 진행  ☐ 1개 → 범위 축소  ☐ 2개 이상 → 다른 업무 |
| 입력이 파일로 준비되는가 | ☐ 예 ☐ 아니오 |
| 출력이 초안·후보·표인가 | ☐ 예 ☐ 아니오 |
| 사람 승인 지점이 있는가 | ☐ 예 ☐ 아니오 |
| 업무 유형 | ☐ A ☐ B ☐ C ☐ D |
| 반복 빈도 | 월 ___ 회 |

셋 이상 "아니오"면 오늘 만드는 대상이 아닙니다. 7일 계획에서 범위를 다시 잡습니다.
