# B2B팀 프로필

> 출처: 김승진 프로 메일 「교육대상 - B2B팀, B2B유통전략팀」(2026-09-04)
> 용도: ②③④ Agent 모두의 참조 파일. GPT 프로젝트 파일 / NotebookLM 소스 / Gemini 에이전트 참조 파일로 업로드합니다.

## 1. 담당 경로

- 고객 중 **대기업 공략**이 중심입니다. 민간 대기업, 대형 건설사가 대표적입니다.
- **공공 경로**도 함께 담당합니다. 초중고, 관공서, 대학.
- 대기업 안에서도 **제조 / 금융 / 통신 / 교육 / 유통 / 서비스** 등 세부 경로별 공략 담당이 따로 있습니다.
- 수요처(고객) **직접 영업**과 **파트너 관리** 업무가 섞여 있습니다.
- 고객의 **구매계획 수립 지원**부터 **재구매 연계를 위한 고객 관리**까지, 장기적인 비즈니스로 공략합니다.

## 2. 주요 품목

- 전 품목을 담당합니다.
- 비중이 큰 품목: **시스템에어컨(SAC), 모바일, IT제품**

## 3. 주요 관리 항목

매출 같은 기본 지표를 제외하면 다음을 관리합니다.

| 항목 | 내용 |
|---|---|
| HVAC 통합 제안 | HVAC 관련 제품·서비스를 통합적으로 제안 |
| 주요 고객 별도 관리 | 대기업 중 매출이 큰 고객을 별도 관리하며 품목 확대를 제안 |
| 주택시장 공략 | 분양 등 주택시장 대응 |
| 선행 지표 관리 | 매출 외 **LEAD**, **BO(비즈니스 오퍼튜니티)** 등 선행 지표 |

## 4. Agent 설계에 주는 의미

| 관리 항목 | Agent에서 어떻게 쓰이나 |
|---|---|
| 세부 경로별 담당 분리 | ② Sensing에서 **업종별로** 필터링해야 합니다. 전체 뉴스를 다 보면 안 됩니다 |
| 장기 관리 | ② 결과에 "거래 상태(신규/기존/휴면)"를 함께 봐야 합니다. 휴면 고객의 재활성 신호가 중요합니다 |
| HVAC 통합 제안 | ③ Action에서 단품이 아니라 **SAC + 제어 + 유지보수 묶음**으로 제안합니다 |
| 품목 확대 | ③에서 최근 거래 품목과 **다른 품목군**을 제안 후보로 봅니다 |
| LEAD·BO 선행 지표 | ④ Analysis의 핵심 지표입니다. 매출만 보지 않고 **단계별 파이프라인**을 봅니다 |

## 5. 이 팀의 Agent가 흔히 틀리는 것

- 업종 필터를 안 걸고 전체 뉴스를 요약한다 → 담당 경로 밖 정보가 섞입니다
- 파이프라인을 **금액 합계만** 보고 단계별 분포를 놓친다 → 선행 지표 관리가 안 됩니다
- 휴면 고객을 신규와 구분하지 않는다 → 재활성 기회를 놓칩니다
- 단품만 제안한다 → HVAC 통합 제안 방침과 어긋납니다
