# 서비스 조건 (B2B유통전략팀 / 실습용 가상 자료)

> 실제 계약 조건이 아닙니다. 실습용 가상 자료입니다.
> **가격·납기·요율은 참고값이며, 제안 자료에 확정 문구로 쓰지 않습니다.**

## 1. DMFP(복사기) 유지보수 — 월 과금 구독

| 구분 | 내용 |
|---|---|
| 과금 방식 | 월 단위 구독. 기기 임대 + 유지보수 + 소모품 포함 |
| 포함 | 정기 점검, 고장 출동, 토너, 드럼 교체 |
| 미포함 | 용지, 사용자 과실 파손, 이전 설치 |
| 최소 약정 | 참고: 12개월 |
| 중도 해지 | 참고: 잔여 기간 위약금 발생 |
| 출동 | 참고: 접수 후 익영업일 |

**위 조건은 참고값입니다.** 실제 약정 기간·위약 조건은 계약 시 확정합니다.

## 2. SAC 설치·유지보수

| 구분 | 내용 |
|---|---|
| 설치 | 소상공인 매장 기준 1~3대. 설치비 별도 |
| 무상 보증 | 참고: 설치 후 일정 기간 |
| 유지보수 | 연 단위 계약 또는 건별 대응 |
| 정기 점검 | 참고: 연 1회 |

## 3. 파트너 지원

| 항목 | 내용 |
|---|---|
| 판매정책 | 분기 단위로 공유. 등급(A/B/C)별 조건 상이 |
| 판촉물 | 제안 자료, 매장 안내물 제공 |
| 교육 | 신규 라인업 도입 시 파트너 대상 설명회 |
| 정산 | 월 단위 |

**등급별 조건 수치는 이 문서에 포함하지 않습니다.** 파트너 등급 조건은 별도 정책 문서에 있으며, 제안 자료에는 "담당자 안내"로 표기합니다.

## 4. 제안 자료 작성 시 규칙

Agent는 다음을 지킵니다.

- 월 구독료·약정 기간·위약금을 **확정 문구로 쓰지 않습니다**
- **등급별 파트너 조건을 추정해 쓰지 않습니다**
- 파트너몰 조건과 온라인몰·직영 조건을 **섞지 않습니다**
- 유지보수 섹션에 `[확인 필요] 구독료·약정·정산 조건: 담당자 확정 필요`를 남깁니다
