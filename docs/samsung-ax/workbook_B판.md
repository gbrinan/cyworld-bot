**업로드가 안 되면** — `06_붙여넣기/`의 마크다운 표를 복사해 붙여넣습니다. 채팅창에 먼저 한 줄: "아래는 첨부 자료입니다. 이 데이터로만 작업하세요."

**결과를 저장하는 법** — AI 출력을 복사 → 메모장 → 파일 이름 정해 저장(HTML은 파일 형식 **모든 파일**) → 다음 모듈에 업로드. AI에게 "파일로 만들어줘"라고 하지 않습니다.

