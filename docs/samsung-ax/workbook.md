### ⑥ 만들 자격이 되는가

```
□ 주 1회 이상 한다
□ Input이 파일로 손에 있다
□ 틀려도 초안이라 되돌릴 수 있다      ← 셋 다 체크되어야 시작합니다
```

**자가 점검**

| 이러면 | 이렇게 |
|---|---|
| 꼬리표가 전부 ✍️ | 아직 쪼개지 않았습니다 |
| 🔒이 하나도 없음 | 대외로 나가는 단계를 빠뜨렸습니다 |
| Input에 "경험"·"감" | 머릿속을 문서로 꺼내거나, 에이전트가 묻게 합니다 |
| 스킬 칸이 비어 있음 | 전부 우리 팀 것일 수 없습니다. 절차·양식·검수는 스킬입니다 |
