# 도구 클릭 경로 — 어디를 눌러 에이전트를 만드나

> 근거: 2026-09-11 김승진 프로가 보낸 사내 화면 캡처(ChatGPT·Gemini).
> 화면은 업데이트로 바뀔 수 있습니다. **리허설에서 한 번 따라가 보고** 다르면 이 문서를 고칩니다.
> 캡처 이미지는 삼성에서 받아 각 절의 `[캡처]` 자리에 넣습니다.

---

## 0. 시작 전

```
□ 사내 포털에 로그인 → ChatGPT 또는 Gemini 타일을 연다
□ 브라우저 탭 두 개: ① AI 창  ② 메모장
□ 오늘 쓸 파일을 바탕화면 폴더에 풀어 둔다
```

---

## 1. ChatGPT — 에이전트 만들기 (주 경로)

```
사이드바 [에이전트]
  └ 우측 상단 [만들기]
      └ 이름        : D_제품추천  (내 이름을 붙이면 목록에서 찾기 쉽습니다)
      └ 설명        : 과거 판매실적으로 버티컬별 추천 제품을 찾는다
      └ [지침]      : 02_prompt/prompt_1.md 의 ✂ 사이를 붙여넣기
      └ [파일 업로드]: 01_data/ 의 파일 2개
      └ [스킬 추가] : (선택) 사용 가능 여부 확인 중 — 리허설 C10
      └ [대화 시작] : 프롬프트 파일 끝의 예시 3개를 입력
      └ [저장]
```

`[캡처]` ChatGPT 에이전트 편집 화면

**모델·추론 수준** — 화면 상단에서 `Instant` 선택. 추론 수준을 고를 수 있으면 `높음`.
**Chat / Work 토글** — 우측 상단. 실습은 어느 쪽이든 됩니다. 조직 디렉터리 공유가 필요하면 `Work`.

### 대안: 프로젝트로 하기 (에이전트가 막혀 있을 때)

```
사이드바 [프로젝트] → [새 프로젝트]
  └ 프로젝트 지침 : 같은 프롬프트를 붙여넣기
  └ 파일 추가     : 같은 파일 2개
  └ 새 대화를 프로젝트 안에서 시작
```

### 대안 2: 그냥 채팅 (둘 다 막혀 있을 때)

```
새 대화 → 프롬프트 전체를 첫 메시지로 붙여넣기 → 파일 첨부(클립 아이콘) → 전송
```
세션이 끊기면 처음부터 다시 붙여넣어야 합니다. `agentD_prompt.txt`를 메모장에 두고 씁니다.

## 2. Gemini — 에이전트 만들기 (대체 경로)

```
사이드바 [에이전트]
  └ [+ 새 에이전트]
      └ "이 단계를 건너뛰고 수동으로 빌드" 를 선택
         (자연어로 만들게 하면 지시문이 요약돼 7블록이 무너집니다)
      └ 지침    : 같은 프롬프트를 붙여넣기
      └ 참조 파일: 업로드 (리허설 C6에서 가능 여부 확인)
      └ [저장]
```

`[캡처]` Gemini 에이전트 만들기 화면

탭 구성: `전체` / `Made by Google` / `내 에이전트` / `Marketplace`.
내가 만든 것은 **내 에이전트**에 있습니다. Marketplace에는 사내 공유 에이전트가 있습니다.

**모델** — `Flash`. Deep Research는 이 과정에서 쓰지 않습니다(월 사용 제한 대비, `tool_budget.md`).

## 3. Gemini Notebook — 자료를 모아 두고 물어보기 (A·B 모듈 보조)

```
[Gemini Notebook] → [+ 새로 만들기]
  └ 소스 추가 : CSV·MD 파일 업로드
  └ 질문은 소스 안에서만 답합니다 (밖의 지식을 섞지 않음)
```

A·B 모듈에서 기사 데이터를 얹어 두고 확인할 때 씁니다. 최종 결과물은 에이전트에서 만듭니다.

---

## 4. 막혔을 때 순서

| 증상 | 다음 시도 |
|---|---|
| [에이전트] 메뉴가 없다 | 프로젝트 (1장 대안) |
| 프로젝트도 없다 | 새 대화에 붙여넣기 (대안 2) |
| 파일 업로드 버튼이 없다 | `06_paste/` 표를 붙여넣기 (`web_environment.md` 5장) |
| 지침란 글자 수가 넘친다 | ⑤ 출력 형식의 예시 블록만 줄이고 ①~④·⑥⑦은 유지 |
| 저장했는데 목록에 없다 | 새로고침 → `내 에이전트` 탭 확인 |
| 결과가 지침을 무시한다 | 새 대화를 열고 첫 메시지로 "지침의 ④ 처리 순서대로 진행해줘" |

---

## 5. 강사용 — 시작 5분에 할 것

1. 화면을 띄우고 **1장 경로를 그대로 한 번 시연**합니다. 말로 설명하지 않습니다.
2. 참가자가 `저장`까지 갔는지 손을 들게 합니다. 여기서 갈리면 이후 30분이 무너집니다.
3. 안 되는 사람은 **대안 2(채팅 붙여넣기)** 로 바로 내립니다. 도구 문제로 실습을 놓치지 않게 합니다.
4. 보조강사는 [에이전트] 메뉴 유무를 기준으로 두 그룹으로 나눠 돕습니다.
