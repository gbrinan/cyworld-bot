## 특이사항 판정 기준

| 기준 | 임계 |
|---|---|
| 해지율 경고 | 파트너별 해지/구독이 **10% 이상** |
| 등급 대비 저조 | A등급인데 B등급 평균 매출 미만 |
| 매출 급변 | 파트너별 전월 대비 ±30% 이상 |
| 재고 과다 | PSI 기말재고가 판매수량의 **2배 이상** |

## 구독 데이터 주의

- `구독건수`는 **당월 유지 중인 건수(누적)**입니다. 매출처럼 월별로 더하면 안 됩니다.
- `해지건수`는 당월 발생분입니다.
- 해지율은 반드시 **분모(구독건수)를 함께** 표기합니다.
