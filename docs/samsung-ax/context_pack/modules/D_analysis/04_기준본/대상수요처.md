## 세션3이 추가로 받아야 하는 것

이 파일만으로는 제안을 쓸 수 없습니다. **매출 헤더에 없는 것들**입니다.

- 요구조건 (무엇을 몇 개, 언제까지)
- 설치 환경 (현장 조건, 기존 장비)
- 경쟁 상황
- 예산

→ 세션3의 `01_데이터/고객요구조건.md`가 이 자리를 채웁니다. **매출 데이터에서 넘어오는 것은 "누구를 고를 것인가"까지입니다.**
