# 웹 접속 환경 전제 — 이 과정이 돌아가는 방식

> 사내 환경은 **웹 브라우저에서 사내 포털을 통해 ChatGPT와 Gemini를 불러 쓰는 방식**입니다.
> 데스크톱 앱, CLI, API, 로컬 설치는 쓰지 않습니다.
> 이 문서는 그 전제에서 실습이 끊기지 않게 하는 절차입니다.

---

## 1. 웹 환경에서 달라지는 네 가지

| 항목 | 데스크톱·CLI였다면 | 웹 포털에서는 |
|---|---|---|
| 결과물 | 파일로 바로 저장 | **화면의 텍스트.** 사람이 복사해 저장해야 함 |
| 다음 단계 인계 | 폴더에서 바로 참조 | **다시 업로드**해야 함 |
| 지시문 보관 | 파일로 상주 | **세션이 끊기면 사라짐.** 따로 보관해야 함 |
| 대용량 계산 | 코드 실행 | 되면 쓰고, **안 되면 소계본으로** |

이 네 가지 때문에 실습이 끊기는 일이 가장 많습니다. 아래 절차를 따르면 막히지 않습니다.

---

## 2. 결과물을 "파일로 저장"하는 방법

이 과정에서 각 모듈이 끝나면 결과를 파일로 저장하라고 합니다. 웹 환경에서 그 방법은 이렇습니다.

```
① AI가 화면에 출력한 결과 전체를 드래그해 복사 (Ctrl+A는 화면 전체가 잡히니 결과 부분만)
② 내 PC에서 메모장 열기 (또는 워드·한글)
③ 붙여넣기
④ 파일 이름을 정해 저장
   customer_profile.md   (메모장이면 customer_profile.txt 도 괜찮습니다)
⑤ 다음 모듈에서 이 파일을 업로드
```

**중요 — AI에게 "파일로 만들어줘"라고 하지 마세요.**
웹 환경에서 AI가 생성한 파일은 다운로드가 막히거나 깨지는 경우가 많습니다. 화면에 텍스트로 출력하게 하고, **사람이 복사해 저장**하는 것이 확실합니다.

지시문 ⑤번(출력 형식) 블록 끝에 이 문장을 넣으면 복사하기 좋게 나옵니다.

```
결과는 파일 첨부가 아니라 화면에 마크다운 텍스트로 출력한다.
사용자가 통째로 복사할 수 있도록 하나의 블록으로 이어서 출력한다.
```

### 저장 파일 이름

| 모듈 | 저장할 파일명 | 형식 |
|---|---|---|
| A Sensing (B2B팀) | `dashboard_A.html` | HTML — 3장 참고 |
| B Sensing (유통전략팀) | `report_B.docx` | Word — 4장 참고 |
| C 제안자료 | `proposal_C.html` | HTML |
| D 데이터 분석 | `recommend_D.html` | HTML |

폴더를 하나 만들어 두면 편합니다. 예: `바탕화면/AX실습_내이름/`

## 3. HTML 결과를 화면에서 꺼내 보는 법

이 과정의 결과물 3개(A·C·D)는 **HTML**입니다. AI는 화면에 `<html>`로 시작하는 코드 덩어리를 출력합니다. 그대로 두면 코드일 뿐이고, 아래 5단계를 거쳐야 보고서로 보입니다.

```
① 코드 블록 오른쪽 위의 [복사] 버튼을 누른다 (드래그보다 정확합니다)
② 메모장을 연다  (시작 → "메모장" 검색)
③ 붙여넣는다 (Ctrl+V)
④ 파일 → 다른 이름으로 저장
     파일 이름 :  recommend_D.html      ← 확장자까지 직접 입력
     파일 형식 :  모든 파일 (*.*)        ← 이걸 안 바꾸면 .txt 가 붙어 안 열립니다
     인코딩   :  UTF-8                  ← 한글이 깨지지 않게
⑤ 저장한 파일을 더블클릭 → 브라우저에서 보고서가 열립니다
```

**확인** — 제목과 표가 보이면 성공입니다. 코드가 그대로 보이면 ④에서 `.txt`로 저장된 것입니다. 파일 이름을 바꿔 `.html`로 끝나게 하면 됩니다.

**출력이 중간에 끊겼다면** 채팅창에 `이어서 출력해줘`라고 하고, 이어진 부분을 메모장의 끝에 붙여넣습니다. `</html>`로 끝나야 완성입니다.

> 삼성 시나리오 문서의 "HTML(확장프로그램 활용)"이 어떤 확장프로그램인지는 확인 중입니다.
> 확장프로그램이 없어도 위 5단계로 결과를 볼 수 있게 설계했습니다.

## 4. Word 보고서를 만드는 법 — B 모듈

B 모듈(유통전략팀)의 결과물은 Word 보고서입니다. AI에게 Word 파일을 만들게 하지 않고, **텍스트를 받아 사람이 Word에 붙여넣습니다.**

```
① AI가 출력한 보고서 전체를 복사
② Word 새 문서를 연다 (회사 보고서 양식이 있으면 그 파일을 먼저 연다)
③ 붙여넣기 → [붙여넣기 옵션]에서 "텍스트만 유지" 또는 "원본 서식 유지" 중 선택
     - 표가 표로 들어오길 원하면 "원본 서식 유지"
     - 회사 양식의 글꼴을 지키려면 "텍스트만 유지" 후 표는 다시 만듦
④ 제목 줄에 회사 양식의 스타일(제목1·제목2)을 적용
⑤ report_B.docx 로 저장
```

**마크다운 표가 `| 열 | 열 |` 그대로 붙는 경우** — 채팅창에 이렇게 다시 요청합니다.

```
표를 마크다운 기호 없이, 항목마다 줄바꿈된 형태로 다시 출력해줘.
```

> 코드 실행이 켜져 있으면 "docx 파일로 만들어줘"도 동작할 수 있습니다.
> 리허설 C4에서 확인한 뒤 강사가 안내합니다. 안 되면 위 절차가 기본입니다.

---

> **밖에서 데이터를 가져와야 할 때** — 네이버 화면의 가격처럼 외부 정보를 표로 가져오는 절차는 `data_capture.md`에 따로 있습니다.
> 크롤러 없이 화면 복사와 캡처로 하는 방법이고, C 모듈에서 씁니다.

## 5. 파일 업로드가 안 될 때

포털 설정에 따라 CSV 업로드가 막혀 있을 수 있습니다. 그때는 **붙여넣기용 표**를 씁니다.

각 모듈의 `06_paste/` 폴더에 모든 데이터가 마크다운 표로 들어 있습니다.

```
modules/D_analysis/06_paste/sales_history.md
modules/D_analysis/06_paste/target_account.md
...
```

붙여넣는 방법
```
① paste/ 폴더에서 해당 .md 파일을 메모장으로 열기
② 표 전체를 복사
③ 채팅창에 먼저 한 줄 적기 — "아래는 첨부 자료입니다. 이 데이터로만 작업하세요."
④ 그 아래에 표를 붙여넣기
```

데이터는 모두 붙여넣을 수 있는 크기로 만들어 두었습니다. 가장 큰 파일도 6KB 정도입니다.

## 6. 코드 실행(데이터 분석)이 안 될 때 — D 모듈

D 데이터 분석 모듈은 판매실적 52행을 집계합니다.

**코드 실행이 되는 경우** — 원본 `sales_history.csv`를 그대로 올려 계산하게 합니다.

**코드 실행이 안 되는 경우** — AI가 52행을 머릿속으로 더하면 **산술 오류가 납니다.** 원본 대신 두 파일을 올립니다.

| 파일 | 내용 | 왜 필요한가 |
|---|---|---|
| `sales_history_소계.csv` | 버티컬·제품군·지역·모델명 네 축의 합계 | 합계 정합성 검산용 |
| `sales_history_호텔모델별.csv` | 대상 버티컬(호텔)의 모델별 건수·수량·금액·수요처수·근거행 | **추천 TOP 3를 뽑으려면 모델 단위 집계가 필요** |

소계본만 올리면 버티컬별 금액까지만 나오고 추천이 안 나옵니다. 두 개를 같이 올려야 합니다.

소계본은 **네 축의 합계가 모두 상세 합계와 일치**하도록 만들어져 있습니다. 그래서 이렇게 검산할 수 있습니다.

```
버티컬별 합계 = 제품군별 합계 = 지역별 합계 = 모델명별 합계 = 570,258,000  → 정상
하나라도 다르면                                                          → 불일치, 중단
```

> **집계를 사람이 먼저 하는 것은 우회가 아니라 순서입니다.**
> 실제 업무에서도 원본 수만 행을 그대로 AI에 던지지 않습니다. 필요한 축으로 줄여서 넘깁니다.
> 무엇을 축으로 삼을지 정하는 것이 사람의 일이고, 그 판단이 결과의 절반입니다.

**학습 목적은 그대로입니다.** 합계 정합성을 대조하고, 안 맞으면 멈추는 훈련입니다. 행 수만 줄었습니다.

### 계산 결과를 믿기 전에

AI가 낸 숫자 중 **하나만 골라 직접 검산**하세요. 소계는 행이 적어 암산이나 계산기로 확인됩니다.

```
예) 버티컬 5개 값을 더하면 전체 합계가 나오나요?
    390,290,000 + 70,800,000 + 51,620,000 + 30,728,000 + 26,820,000 = 570,258,000  ✓
```

한 개가 맞으면 나머지도 대체로 맞습니다. 한 개가 틀리면 전부 다시 시킵니다.

## 7. 세션이 끊겼을 때 — 지시문 보관

웹 채팅은 창을 닫거나 세션이 만료되면 지시문이 사라집니다. Gemini는 Gems를 쓸 수 없어 더 그렇습니다.

**그래서 지시문을 처음부터 내 PC에 두고 씁니다.**

```
① 모듈 폴더의 `02_prompt/prompt_1.md`를 메모장으로 연다 (또는 직접 작성)
② agentD_prompt.txt 로 내 PC에 저장 (모듈마다 하나씩)
③ 채팅창에 붙여넣어 사용
④ 고칠 때는 메모장에서 고치고 다시 붙여넣기
```

이렇게 하면 세션이 끊겨도, 다음 차수에 다시 써도, 동료에게 넘겨줄 때도 그대로 됩니다.
**이게 이 과정이 말하는 "컨텍스트를 데이터로 다룬다"의 가장 작은 실천입니다.**

> **ChatGPT의 Skills 기능이 열려 있다면** 메모장 보관 대신 Skill로 등록해 워크스페이스에 공유할 수 있습니다.
> 만드는 내용(지시문 7블록 + 참조 자료)은 똑같고 보관 장소만 달라집니다.
> 사내에서 켜져 있는지는 리허설에서 확인합니다 — `skills_and_mcp.md` 4장 참고.

## 8. 실습 시작 전 3분 점검

각 모듈 시작 전에 확인합니다.

```
□ 포털에서 ChatGPT / Gemini에 접속됨
□ 탭을 두 개 열어둠 (① AI 창  ② 메모장 또는 워드)
□ 오늘 쓸 폴더를 만들어 둠 (바탕화면/AX실습_내이름/)
□ 팩에서 이번 모듈 폴더를 열어둠 (`modules/D_analysis/` 등)
□ 파일 업로드가 되는지 1건으로 확인 → 안 되면 06_paste/ 사용
□ 코드 실행이 되는지 확인 → 안 되면 소계본 + 집계본으로 교체
```

**업로드 테스트는 작은 파일로 먼저 합니다.** `target_account.md`(1KB 미만)가 적당합니다. 큰 파일로 시도하다 실패하면 시간이 날아갑니다.

**코드 실행 테스트 한 줄** — `올린 파일의 행 수와 판매금액 합계만 알려줘.` 합계가 570,258,000이면 계산이 되는 환경입니다.

## 9. 자주 막히는 지점

| 증상 | 원인 | 대응 |
|---|---|---|
| 파일 업로드 버튼이 없음 | 포털 설정 | `paste/` 표를 붙여넣기 |
| 업로드했는데 "읽을 수 없다"고 함 | 인코딩 또는 용량 | 팩 원본을 다시 받거나 `paste/` 사용 |
| AI가 만든 파일이 다운로드 안 됨 | 웹 환경 제약 | **정상입니다.** 화면 출력을 복사해 저장 |
| 새로고침하니 지시문이 사라짐 | 세션 초기화 | 보관해 둔 `agent*_prompt.md`를 다시 붙여넣기 |
| 숫자가 매번 다르게 나옴 | 코드 실행 없이 암산 | 소계본으로 바꾸고 한 개를 직접 검산 |
| 한글이 깨져 보임 | 인코딩 | `06_paste/` 마크다운 표 사용, 저장 시 UTF-8 선택 |
| 저장한 html이 코드로 보임 | `.txt`로 저장됨 | 파일 이름을 `.html`로 끝나게 바꾸기 (3장) |
| 결과가 중간에 끊김 | 출력 길이 제한 | `이어서 출력해줘` 후 메모장 끝에 이어붙이기 |
| 추천이 안 나오고 금액만 나옴 | 소계본만 올림 | `sales_history_호텔모델별.csv`도 같이 올리기 (6장) |

## 10. 아직 확인되지 않은 것

아래는 삼성 담당자 확인이 필요한 항목입니다. 확인 결과에 따라 이 문서를 갱신합니다.

| 항목 | 확인 내용 | 안 되면 |
|---|---|---|
| 파일 업로드 | 포털 경유로 CSV·MD 업로드가 되는가 | `paste/` 경로로 전환 |
| 코드 실행 | ChatGPT 데이터 분석(코드 실행)이 동작하는가 | 소계본 경로로 전환 |
| 프로젝트·GPTs | 포털에서 프로젝트 생성·GPTs 제작이 되는가 | 지시문 붙여넣기 방식으로 |
| Gemini 에이전트 | 포털에서 에이전트 기능과 참조 파일이 되는가 | 지시문 + 붙여넣기 방식으로 |
| 결과 복사 | 출력 텍스트 복사에 제한이 있는가 | 있으면 실습 설계를 다시 봐야 함 |
| 세션 유지 시간 | 얼마 만에 만료되는가 | 짧으면 모듈을 더 잘게 나눔 |
| **실습 파일 배포** | 참가자 PC로 CSV를 어떻게 전달하는가 (사내 메일·공유 폴더·USB) | 배포가 막히면 `06_paste/` 표를 인쇄물·슬라이드로 |
| **HTML 확장프로그램** | 시나리오 문서의 "확장프로그램"이 무엇인가 | 3장 5단계로 진행 |

**모든 항목이 안 되더라도 이 과정은 진행됩니다.** 붙여넣기와 복사만 되면 네 Agent를 다 만들 수 있게 설계했습니다.
