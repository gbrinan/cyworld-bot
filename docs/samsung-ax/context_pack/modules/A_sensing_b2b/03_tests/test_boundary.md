# 경계 테스트 — A_sensing_b2b (단계 2)

## 입력
- **아무 파일도 올리지 않습니다.**
- 지침: `02_prompt/prompt_2_프로파일.md`의 ✂ 사이
- 첫 메시지: `프로파일 만들어줘.`

## 기대 행동
- 프로파일을 만들지 **않고** **회사명부터 질문한다.**
- **한 번에 하나씩** 묻는다. 6개 질문을 한꺼번에 던지지 않는다.
- 내가 "모른다"고 답하면 그 항목을 `확인 필요`로 비워 두고 **다음 질문으로 넘어간다.**
- 마지막에 **비어 있는 항목과 누구에게 물으면 되는지**를 적는다.

## 진행 시나리오 (강사가 답하는 내용)
| 질문 | 이렇게 답한다 |
|---|---|
| 회사명 | 한울종합건설 |
| 상장 시장 | 코스닥 |
| 주력 공종 | 호텔·상업시설 |
| 최근 수주 현장 | **모른다** |
| 거래 이력 | 신규 |
| 접점 | **모른다** |
| 왜 지금인가 | 호텔 리뉴얼 기사를 봤다 |

기대 결과는 `04_answer/customer_profile.md`와 같은 모양입니다. **빈 항목이 남아 있어야 정답입니다.**

## 통과 기준
- [ ] 첫 응답에 프로파일 내용이 없고 질문만 있다
- [ ] 질문이 한 번에 하나씩 온다
- [ ] "모른다"에 대해 추정해 채우지 않는다
- [ ] 마지막에 빈 항목 목록이 나온다

## 안 되면
- 회사명만 주면 나머지를 알아서 채운다 → **가장 흔한 실패입니다.** 지침의 "추정해 채우지 않는다"를 ⑦ 성공 기준에도 한 번 더 넣습니다.
- 6개를 한꺼번에 묻는다 → 부분 통과. "한 번에 하나씩 물어줘" 되묻기.

## 이 테스트가 보여주는 것
**다른 모듈에서 질문은 통과 조건이었지만 여기서는 질문이 기능입니다.**
신규 고객 조사는 원래 아는 것부터 적고 모르는 것을 표시해 두는 일입니다. 빈칸이 남은 프로파일이 채워진 가짜 프로파일보다 낫습니다.
