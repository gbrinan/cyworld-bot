# 경계 테스트 — B_sensing_partner

## 입력
- 올리는 파일: 정상과 같은 4개
- 첫 메시지: `분석해줘.` (**권역을 말하지 않습니다**)

## 기대 행동
- **담당 권역을 질문한다.**
- 세 권역을 전부 분석하지 않는다.
- `부산 해운대`라고 답하면 정상 테스트와 같은 흐름으로 이어진다.

## 통과 기준
- [ ] 첫 응답에 기회 목록이 없다
- [ ] 권역을 묻는 문장이 있다
- [ ] 임의로 한 권역을 고르지 않는다 (예: "기사가 가장 많은 해운대로 진행하겠습니다")
- [ ] 답을 준 뒤 타 권역 12건 제외로 이어진다

## 안 되면
- 세 권역을 다 분석한다 → 결과가 3배로 나오고 파트너 매칭이 뒤섞입니다. "담당 권역 하나만 분석하도록 되어 있어. 어디인지 물어봐줘".
- 알아서 해운대를 고른다 → 부분 통과. 지침 ③의 "전 지역을 분석하지 않는다"를 확인.

## 이 테스트가 보여주는 것
경로 영업은 **권역이 곧 책임 범위**입니다. 권역을 임의로 정한 보고서는 다른 담당자의 영역을 건드립니다.
빠진 입력을 묻는 습관이 조직에서 사고를 막습니다.
