## 제작 메모

강의장 기준입니다 — 40~50명, 스크린 하나, 뒷줄 10m, 참가자는 노트북을 열어 두고 절반은 AI가 처음.

- **꼬리표 4종은 덱 전체에서 같은 모양·같은 색·같은 이름**으로 씁니다. 이모지가 아니라 **선 아이콘 + 글자 라벨**입니다. 아이콘만 두면 참가자는 못 읽고, 빔에서 자물쇠와 톱니는 구분되지 않습니다.
- **단계 박스는 항상 에이전트 테두리 안에** 넣습니다. 단계를 에이전트처럼 그리면 안 됩니다. 에이전트는 모듈당 하나입니다.
- 타임바는 A·B·C가 같고 **첫 모듈 D만 다릅니다**(위 6시간 배치표). 타임바는 지금 어느 칸인지 표시할 수 있게 칸을 나눕니다.
- **실습 슬라이드 8장은 텍스트를 줄이지 않습니다.** 30분 넘게 멈춰 있는 유일한 작업 지시서입니다. 여섯 가지가 다 들어갑니다 — ①지금 만드는 것(모듈·단계) ②이번에 쓰는 파일 이름(mono, 정확한 철자) ③할 일 + 시간 막대(종료 시각 빈칸 `__:__ 까지`) ④됐다는 신호 3개 ⑤막혔을 때 3줄 ⑥"지시문은 화면에서 옮겨 적지 말고 배포 파일에서 복사".
