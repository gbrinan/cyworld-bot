### 타입

대체 스택은 `'Apple SD Gothic Neo', 'Noto Sans KR', 'Malgun Gothic'` 순서로 둡니다. **Arial로 떨어지면 안 됩니다.**

### 그리드와 마스터

```
1280 × 720 (16:9)
여백  좌우 64 / 상 48 / 하 40      표지만 예외
헤더  라벨 + 제목 + 우측 캡션 한 줄, 하단 2px 잉크선
푸터  1px 룰 위에  좌 '모든 데이터는 가상입니다'  /  우 '블록 · 페이지'
```

### 반드시 지킬 것 — 시안에서 실제로 터진 것들

| 규칙 | 왜 |
|---|---|
| **카드에 1px 테두리를 넣는다** | 카드와 바탕의 명도 차가 2%뿐입니다. 빔과 흑백 인쇄에서 경계가 사라집니다 |
| **비율이 정보인 도식은 `flex: N 0 0`** | `flex-grow`만 쓰면 라벨 글자 수가 폭에 더해집니다. 30분이 20분과 같은 크기로 나옵니다 |
| **한 줄에 세 항목이면 `flex-wrap`** | 세로보다 가로가 먼저 터집니다 |
| **4px 좌측 룰은 경고 박스 전용** | 다른 강조는 3px이거나 배경 `#EEF0EA` |
| **푸터에 제작 메모를 쓰지 않는다** | "이 레이아웃은 8장에 반복됩니다"가 관객에게 그대로 투사됩니다 |
| **이모지 대신 선 아이콘** | 인쇄·확대에서 깨지고 색을 못 바꿉니다 |
