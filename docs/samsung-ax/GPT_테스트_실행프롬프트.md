# GPT에게 시키는 실습 테스트 프롬프트

ChatGPT **새 채팅**에서 모델 추론 강도를 **높음(high)**으로 두고 아래처럼 진행합니다.

- **첨부:** `AX_실습파일.zip`과 `GPT_테스트_체크리스트.md`
- **도구:** 데이터 분석(코드 실행) 켜기. 22번(IT 법령 변화)까지 보려면 웹 검색도 켜기

GPT는 에이전트를 직접 만들 수 없습니다. 그래서 각 `…Agent_지침.md`를 "그 에이전트의 지침"으로 삼아 실습을 대신 돌려 보게 하고, 결과를 체크리스트와 대조시킵니다. 기대값을 미리 보면 답을 맞춰 쓰게 되므로, **실행이 끝난 뒤에만** 체크리스트를 열게 합니다.

> 슬라이더 조작(8번)이나 "대화로 돌아가기"(16번)처럼 사람이 화면에서 해야 하는 것은 GPT가 대신 판정하지 못합니다. 이런 줄은 `수동 확인`으로 남기게 했습니다. 실제 에이전트 화면에서 사람이 한 번 더 확인해 주세요.

## ✂ 여기서부터 복사

#Role 너는 교육용 AI 에이전트 실습 자료를 검수하는 QA 담당이다. 참가자 입장에서 실습을 그대로 따라 해 보고, 기대 결과와 다른 곳을 찾는다.

#Action 첨부한 `AX_실습파일.zip`을 풀고, 아래 순서대로 실습을 실제로 돌린 다음, 그 결과를 `GPT_테스트_체크리스트.md`와 대조해 판정해라.

#Context
- 폴더마다 `2_… Agent_지침.md`가 **그 에이전트의 지침**이고, `…_실습프롬프트….md`는 참가자가 그 에이전트에게 보내는 **메시지**다. 데이터(.xlsx · .md · .json)는 같은 폴더에 있다.
- 너는 에이전트를 만들 수 없으니, 단계마다 **그 지침을 너의 지침으로 삼아** 실습프롬프트에 답한다. 다른 폴더로 넘어갈 때는 **새 대화처럼** 앞 단계의 지침을 잊고 시작한다. "같은 대화에 이어서"라고 적힌 프롬프트만 앞 맥락을 이어 쓴다.
- 지침이 "멈추고 물어라"라고 하면 실제로 멈춘 응답을 그대로 기록하고, 참가자가 할 다음 답(예: "샘플값 그대로")은 그다음 실습프롬프트로 보낸 것으로 친다.
- 숫자는 반드시 코드로 계산한다. 어림하지 않는다.

**실행 순서**

1. `2. 시장Sensing`: 지침 → `3_…실습프롬프트1` → `4_…실습프롬프트2` (기사수집 · 대상고객사 첨부, 기준일 2026-09-01)
2. `3-1. 대시보드`: 지침 → `2_…실습프롬프트`(첫 응답을 그대로 기록) → `3_…설정확인` → `4_` · `5_` · `6_` 현황파악 1~3 (매출데이터 · 소계 첨부). 대시보드 HTML은 파일로 저장해 두고, 7번 목표 대비 · 8번 시뮬레이션 숫자를 따로 적는다.
3. `3-2. 데이터 분석`: 새 대화로 지침 → 두 파일 다시 첨부 → `3_…가설확인` → 보고서 맨 아래 인계본을 `대상수요처.md`로 저장 → `4_…대시보드고치기`는 2번의 대시보드 맥락으로 돌아가 실행
4. `4. 제안자료`:
   - 지침 → 3개 파일 + 방금 저장한 `대상수요처.md` → `3_…실습프롬프트1` → `4_…실습프롬프트2`
   - 같은 지침으로 새 대화를 열어 **`대상수요처.md` 없이** `3_…실습프롬프트1`을 보내고 첫 응답만 기록
   - `5_대응보고서`(2번 8번 결과를 붙여넣기) → `6_PPT차트만들기` → `7_IT법령변화`(웹 검색이 꺼져 있으면 '검색 불가'로 기록)

**실행이 끝난 뒤에만** `GPT_테스트_체크리스트.md`를 열어 22줄과 대조한다.

#Style
① 단계별 실행 기록: 단계 번호 · 보낸 파일 · 응답 요약 5줄 이내 · 핵심 숫자. 멈추고 물은 응답은 원문 그대로.

② 판정 표: `# | 기대 결과 | 실제 결과 | 판정(통과 · 부분 · 실패 · 수동 확인) | 원인(지침 몇 번 블록 · 데이터 · 프롬프트 중 어디)`. 숫자는 체크리스트와 같은 단위로 쓴다. 표 모양 · 문장은 달라도 숫자 · 판정 · 순서가 같으면 통과다.

③ 실패 · 부분 줄마다 고칠 곳 한 줄: 어느 파일의 어느 문장을 어떻게 바꾸면 되는지. 고친 문장을 실제로 써 보이되, 파일은 고치지 마라.

④ 맨 아래 세 줄 요약: 통과 n / 부분 n / 실패 n / 수동 확인 n, 가장 먼저 고칠 것 1개.

지어내지 마라. 응답에 없는 값은 '없음'으로 적는다. 판정이 애매하면 '부분'으로 두고 이유를 쓴다.
