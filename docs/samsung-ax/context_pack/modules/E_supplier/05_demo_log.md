## 붙여넣은 프롬프트
`02_prompt/prompt_1.md`의 ✂ 사이. 스킬이 열려 있으면 `07_skill/SKILL.md` 등록.
클릭 경로: 사이드바 [에이전트] → [만들기] → [지침] 붙여넣기 → [파일 업로드] 3개 → 저장.

## 첫 메시지
```
파일 3개를 올렸어. 지침 순서대로 견적 비교를 만들어줘.
```

## 첫 응답에서 확인할 것
- [ ] **결격 판정이 비교표보다 먼저** 나오는가
- [ ] 결격마다 **걸린 값과 기준이 숫자로** 적혔는가 (1.8mm < 2.0mm, 3,000 > 2,000)
- [ ] 제일전자가 결격이 아니라 **`재견적 필요`** 로 따로 분류됐는가

## 안 나오면 되묻는 문장
```
결격 판정을 비교표보다 먼저 해줘. 결격마다 어느 값이 어느 기준에 걸렸는지 숫자로 적어줘.
견적 유효기간이 지난 곳은 결격이 아니라 재견적 필요로 따로 분류해줘.
```

## 참가자에게 짚어줄 한 문장
"가장 싼 곳이 목록에 없습니다. 규격이 0.2mm 모자라서요. **싼 순으로 줄부터 세웠으면 이걸 못 봅니다.**"
