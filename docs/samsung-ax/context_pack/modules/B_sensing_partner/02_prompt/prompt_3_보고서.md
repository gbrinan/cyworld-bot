# B 단계 3 — 양식에 맞춰 출력

> 단계 2와 **같은 에이전트, 같은 지침**입니다. 이 파일은 단계 3을 진행하는 **대화 메시지**입니다.
> Word로 옮기는 절차는 `common/web_environment.md` 4장.

---

## ✂ 여기서부터 복사

앞의 분석 결과를 지침 ⑤번 양식의 **Word 보고서**로 출력해줘.

- 5개 절을 순서대로 (권역시장 요약 / Key Sales Signal / 영업기회 리스트 / 근거 / 파트너사와 논의사항)
- 1절에는 시장조사 지표를 근거로 쓰고, **규모 미달로 기회 목록에 못 올린 작은 시설 건수**도 흐름으로 적어줘
- 3절 표에 담당 파트너 칸을 넣고, 맞는 파트너가 없으면 "해당 파트너 없음 — 부족한 조건"을 적어줘
- 4절에는 기회마다 기사 제목·원본url과 상권정보 확인 여부를 적어줘
- 5절은 파트너별로 묶어서, 누가·언제·무엇을 논의할지 적어줘

**Word에 붙여넣을 것이라 표는 마크다운 표로 만들어줘.** 파일로 만들지 말고 화면에 텍스트로 출력해줘.
