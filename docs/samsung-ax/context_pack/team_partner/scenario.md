# B2B유통전략팀 통합 시나리오 — 사업자몰 라인업·맞춤 마케팅

> 출처: 9/7 사전 모임 슬라이드 STEP 3의 B2B유통전략팀 후보 예시
> 사전과제 목적대로 **영업 여정(Sensing → Action → Analysis)을 1개 시나리오로 통합**했습니다.
> 확정본은 9/8 전달 자료 반영 후 갱신합니다.

---

## 상황

당신은 B2B유통전략팀에서 SMB 파트너를 관리합니다.
4분기에 **사업자몰 라인업을 개편**하고, 파트너가 소상공인에게 쓸 맞춤 제안 자료를 만들어야 합니다.

지금은 이렇게 일합니다.

1. 업종별 수요 데이터와 경쟁사 몰을 각각 열어보며 감으로 라인업을 잡습니다.
2. 파트너가 요청하면 그때그때 제안 자료를 만들어 보냅니다. 파트너마다 내용이 다릅니다.
3. 월말에 파트너별 매출과 구독 해지를 정리합니다. 구독은 누적이라 매번 다시 셉니다.

---

## 세 Agent가 이어지는 흐름

```
② Sensing   업종별 수요 + 경쟁사 라인업·가격·프로모션
            → 어떤 세그먼트에 어떤 품목을 밀 것인가
            → segment_profile.md

③ Action    segment_profile.md + 사업자몰 라인업 + 서비스 조건
            → 파트너 배포용 제안 자료 (회사소개 → 제안내용 → 제품소개 → 유지보수)
            → proposal_draft.md

④ Analysis  파트너별 매출·구독 + 온라인 가격·PSI
            → 라인업 성과, 구독 해지, 파트너 등급별 현황
            → report_draft.md
```

---

## 모듈별 실습 정의

### ② 시장·고객 분석 Agent (Sensing)

| 항목 | 내용 |
|---|---|
| 업무 상황 | 소상공인 업종별 수요와 경쟁사 라인업·가격·프로모션을 비교해 4분기 밀 품목과 대상 세그먼트를 정한다 |
| 입력 | `data/smb_demand.csv` (24행), `data/competitor_lineup.csv` (32행) |
| 필수 컬럼 | 기준월, 업종, 지역, 문의건수, 관심품목군, 평균구매액, 전월대비 / 경쟁사, 품목군, 표시가, 프로모션, 채널 |
| 기준일 | 2026-09-04, 분석 기간 2026-07 ~ 2026-09 |
| 관심 지표 | 업종별 문의 추이, 평균구매액, 경쟁사 프로모션 유형, **채널별(파트너몰/온라인몰/직영) 조건 차이** |
| 우선순위 기준 | ① 문의건수 규모 ② 전월대비 추이 ③ 평균구매액 ④ 경쟁사 프로모션 강도 |
| 출력 | `segment_profile.md` — 세그먼트 우선순위 표 + 상위 3건 상세 + 근거표 |
| 이 데이터의 함정 | **`전월대비` 컬럼이 `문의건수` 추이와 어긋납니다.** 예: 사무서비스는 193→225→278로 늘었는데 컬럼에는 '감소'로 적혀 있습니다. 파생 컬럼을 그대로 믿지 말고 원본 수치에서 다시 계산해야 합니다 |

### ③ 제안자료 작성 Agent (Action)

| 항목 | 내용 |
|---|---|
| 업무 상황 | ②에서 뽑은 1순위 세그먼트를 대상으로, **파트너가 소상공인에게 쓸** 제안 자료 초안을 만든다 |
| 입력 | `handoff/segment_profile.md`(② 결과), `data/product_catalog.csv` (7행), `data/service_terms.md` |
| 독자 | **1차 독자는 파트너 영업 담당**, 2차 독자는 소상공인 사업주 |
| 제안 규모 | 매장 1~3대 규모, 구독형 우선 |
| 출력 | `proposal_draft.md` — 회사소개 / 제안내용 / 제품소개 / 유지보수 + 근거표 + 확인 필요 |
| 이 팀 특성 반영 | **구독 중심**: DMFP는 판매가 아니라 월 과금으로 제안합니다. **채널 구분**: 파트너몰 조건과 온라인몰 조건을 섞지 않습니다 |
| 이 데이터의 함정 | 독자가 파트너인데 소상공인에게 직접 말하듯 쓰면 틀립니다. 독자를 지정하지 않으면 Agent가 질문해야 합니다 |

### ④ 데이터 분석 Agent (Analysis)

| 항목 | 내용 |
|---|---|
| 업무 상황 | 월말 파트너별 매출과 구독 현황을 정리하고, 라인업 성과와 해지 신호를 보고한다 |
| 입력 | `data/partner_sales.csv` (60행), `data/online_price_psi.csv` (12행), `data/monthly_summary.csv`, `data/report_template.md` |
| 필수 컬럼 | 기준월, 파트너코드, 파트너명, 등급, 품목군, 매출(천원), 수량, 구독건수, 해지건수 |
| 기준월 | 2026-09, 비교 2026-08 (필요시 2026-07) |
| 핵심 지표 | 파트너별·등급별 매출, 품목군별 매출 비중, **구독 순증(구독-해지)**, 해지율, PSI 재고 회전 |
| 특이사항 기준 | 등급 대비 매출이 하위인 파트너, 해지건수가 구독건수의 10% 이상, 재고가 판매의 2배 이상 |
| 출력 | `report_draft.md` — 데이터 점검 / 요약 / 지표 현황 / 특이사항 / 근거표 |
| 이 데이터의 함정 | **구독은 누적 수치입니다.** 매출과 같이 단순 합산하면 안 됩니다. 표지와 상세 합계 대조도 필요합니다 |

## 완주 체크

```
□ ② segment_profile.md 저장 — 규모와 추이를 함께 봤는가
□ ③ proposal_draft.md 저장 — 독자를 파트너로 지정했는가
□ ④ report_draft.md 저장 — 구독을 누적으로 다뤘는가, 합계를 대조했는가
□ 테스트 3종 로그 기록
□ 내 업무 전환 표 작성
```
