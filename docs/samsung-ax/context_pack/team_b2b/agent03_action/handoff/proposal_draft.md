## 2. 제안내용

### 2.1 고객 과제

신사옥 착공(2026-07-29 보도)과 신규 지점 개설 계획(2026-07-28 보도)이 동시에 진행되고 있습니다. 여기에 스마트오피스 전환도 추진 중입니다(2026-08-01 보도).

공간이 여러 곳에서 동시에 만들어질 때, 공조 설비와 업무 환경을 부서별로 따로 발주하면 사양과 유지보수 창구가 갈립니다. *(과제 가설 — 근거: customer_profile.md 1순위 항목)*

### 2.2 해결 방향

**HVAC 통합 구성**을 제안합니다.

1. 사무동 층별 공조를 시스템에어컨으로 구성합니다.
2. 중앙 제어 컨트롤러로 층·구역을 한 화면에서 운전·모니터링합니다.
3. 유지보수를 단일 계약으로 묶어 창구를 하나로 만듭니다.
4. 스마트오피스 전환에 맞춰 업무용 모바일 기기를 함께 검토합니다.

### 2.3 기대 효과

- 운전 현황을 중앙에서 확인할 수 있어 층별 개별 확인 절차가 줄어듭니다. *(정성적 서술 — 절감률 수치는 자료에 없어 쓰지 않았습니다)*
- 유지보수 창구가 하나로 정리됩니다.

`[확인 필요]` 에너지 절감률, 투자 회수 기간 — 고객사 현재 설비 정보가 없어 산출하지 않았습니다.
