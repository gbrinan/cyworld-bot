# 유지보수 서비스 조건 (B2B팀 / 실습용 가상 자료)

> 실제 계약 조건이 아닙니다. 실습용 가상 자료입니다.
> **가격·납기·SLA 수치는 참고값이며, 제안서에 확정 문구로 쓰지 않습니다.**

## 1. 서비스 범위

| 구분 | 포함 | 미포함 |
|---|---|---|
| 정기 점검 | 연 2회 필터·냉매·전장 점검 | 건물 배관·전기 공사 |
| 고장 대응 | 원격 진단, 현장 출동, 부품 교체 | 사용자 과실·천재지변 손상 |
| 중앙 제어 | 컨트롤러 펌웨어 업데이트, 운전 데이터 리포트 | 고객사 시스템 연동 개발 |
| 소모품 | 표준 필터 (연 2회) | 고급형 필터, 추가 교체분 |

## 2. 대응 체계 (참고값)

| 등급 | 접수 채널 | 1차 응답 | 현장 출동 |
|---|---|---|---|
| 긴급 (전면 정지) | 전용 회선 | 참고: 1시간 이내 | 참고: 당일 |
| 일반 (부분 이상) | 전용 회선·웹 | 참고: 4시간 이내 | 참고: 익영업일 |
| 문의 | 웹 | 참고: 1영업일 | 해당 없음 |

**위 시간은 참고값입니다.** 실제 SLA는 계약 시 확정합니다. 제안서에는 "협의" 또는 "확인 필요"로 표기합니다.

## 3. 계약 형태

- 기본: 설치 후 **무상 보증 기간** + 이후 연 단위 유지보수 계약
- 통합 계약: SAC + 중앙 제어를 함께 계약하면 단일 창구로 운영 가능
- 무상 보증 기간, 유지보수 요율, 갱신 조건은 **영업 담당이 확정**합니다

## 4. 제안서 작성 시 규칙

Agent는 다음을 지킵니다.

- 대응 시간·요율·기간을 **확정 문구로 쓰지 않습니다.** "참고", "협의 예정"으로 표기합니다
- 이 문서에 없는 서비스 항목을 만들지 않습니다
- 유지보수 섹션에 반드시 `[확인 필요] 가격·납기·SLA: 영업 담당 확정 필요`를 남깁니다
