**세션1과 이어지는 가설** — 세션1에서 모은 기사 중 「미래로병원 증축 설계 수주」가 있습니다. 6월부터 구매가 줄어든 것이 신관 공사 때문이라면, 완공 무렵 **신관에 새로 필요한 것**이 생깁니다. 세션3의 요구조건(신관 회의공간)이 바로 그것입니다.

## 세션3이 추가로 받아야 하는 것

이 파일만으로는 제안을 쓸 수 없습니다. **매출 헤더에 없는 것들**입니다.

- 요구조건 (무엇을 몇 개, 언제까지)
- 설치 환경 (현장 조건, 기존 장비)
- 경쟁 상황
- 예산

→ 세션3의 `01_데이터/고객요구조건.md`가 이 자리를 채웁니다. **매출 데이터에서 넘어오는 것은 "누구를 고를 것인가"까지입니다.**
