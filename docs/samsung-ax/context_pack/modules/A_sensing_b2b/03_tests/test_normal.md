# 정상 테스트 — A_sensing_b2b

## 입력
- 올리는 파일: `01_data/rss_feed.csv`, `01_data/target_builders.csv`
- 지침: `02_prompt/prompt_3_분석.md`의 ✂ 사이 (또는 `07_skill/SKILL.md` 등록)
- 첫 메시지: `rss_feed.csv와 target_builders.csv를 올렸어. 기준일은 2026-09-01이야. 지침 순서대로 대시보드를 만들어줘.`

## 기대 행동
1. 수집 요약에 **원본 30건 → 중복 3건 제외 → 27건**이 나온다.
2. 수요처별 기사 수가 대성건설 4 · 한울종합건설 3 · 서진이엔씨 2 · 기타 18이다.
3. Key Signal에 근거 행 번호가 붙는다.
4. **서진이엔씨가 `보류`로 분류**된다. 기회 목록에 들어가면 안 된다.
5. 우선순위가 **접근 시점 기준**으로 정렬된다.

| 순위 | 수요처 | 준공 | 접근 시점 | 기준일 대비 |
|---|---|---|---|---|
| 1 | 한울종합건설 강릉 호텔 | 2027-03 | **2026-09** | 지금 |
| 3 | 대성건설 오피스동 | 2028-06 | 2027-12 | 15개월 뒤 |

6. **대성건설이 1순위가 아니다.** 수주 1.2조로 규모는 크지만 시점이 멀다.
7. 1순위에 **시나리오 2개 이상**이 있고 갈래마다 행동이 다르다.
8. 접점이 없다는 것이 드러나고 "접점 확보"가 첫 행동으로 나온다.

## 통과 기준
- [ ] 중복 3건 제외가 보고된다
- [ ] 서진이엔씨가 보류로 분류된다
- [ ] 접근 시점이 준공에서 6개월 뺀 값으로 계산된다
- [ ] 1순위가 한울종합건설이다 (대성건설이 아니다)
- [ ] 시나리오가 2개 이상이다

## 안 되면
- 대성건설을 1순위로 올린다 → 규모로 정렬한 것. "우선순위를 접근 시점 기준으로 다시 정렬해줘" 되묻기.
- 서진이엔씨를 기회에 넣는다 → 지침 ④-6을 다시 읽게 한다. "실적 악화 신호가 있는 수요처는 어떻게 분류하기로 했지?"
- 접근 시점을 안 낸다 → "준공 예정일에서 6개월을 빼서 접근 시점을 계산해줘".
- 시나리오가 하나다 → `prompt_3_분석.md`의 대화 시작 예시 3번을 보낸다.
