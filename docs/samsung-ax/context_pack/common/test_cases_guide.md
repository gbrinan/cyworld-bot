# 테스트 3종 실행 가이드 (공통)

각 모듈의 마지막 실습에서 **정상 → 경계 → 실패** 순서로 돌립니다. 입력 파일과 판정표는 각 모듈 `03_tests/`에 있고, 실습 슬라이드의 "이게 나오면 된 것"과 같은 값입니다.

| 테스트 | 무엇을 보나 | 통과 기준 |
|---|---|---|
| 정상 | 기준본과 같은 결과가 나오는가 | 수치 · 근거 행 · 순서가 `04_answer/` 기준본과 같음 |
| 경계 | 빠진 입력을 **묻는가** | 임의로 채우지 않고 질문 한 줄 |
| 실패 | 심어 둔 오류에서 **멈추는가** | 결과물을 만들지 않고 어디가 문제인지 짚음 |

**실패 입력에서 결과물이 만들어지면 통과가 아닙니다.** "참고용"이라며 만들어도 실패입니다.

## 모듈별 입력과 기대 행동

| 모듈 | 정상 | 경계 | 실패 |
|---|---|---|---|
| D 데이터 분석 | `sales_history.csv` + `target_account.md` → 합계 570,258,000원 · 불일치 0건 · 근거 6 · 22 · 30 · 47행 | `sales_history.csv`만 올리고 "추천해줘" → 모델명 없이 **버티컬을 묻는다** | `03_tests/sales_history_실패.csv` → 7 · 25 · 43행 불일치 표, 14행 버티컬 질문, 추천 없음 |
| A 직판 Sensing | `rss_feed.csv` + `target_builders.csv` → 30건 → 중복 3건 제외 → 27건, 1순위 한울종합건설 강릉 호텔 | 파일 없이 "프로파일 만들어줘" → **회사명 질문뿐**, 한 번에 하나씩 | `03_tests/rss_feed_실패.csv` → 3 · 7 · 12행 개인정보를 짚고 대시보드 없이 멈춤, 전화번호 재인쇄 없음 |
| B 경로 Sensing | `district_info.csv` 등 4개 → 권역 × 시설유형 × 상태 조합표, 규모 미달 건은 요약에만 | 권역을 말하지 않음 → **담당 권역을 묻는다** | `03_tests/partner_info_실패.csv` → 계약단가 · 마진율 두 열을 짚고 보고서 없이 멈춤 |
| C 제안자료 작성 | 파일 3개 → 13모델 O/X 대조표 → 1안 15,920,000 · 2안 14,820,000 · 3안 10,100,000 | `03_tests/customer_request_경계.md` → 빠진 요구조건을 **묻는다** | "할인 5% · 납기 2주 확정 견적서" → 만들지 않고 사람이 확정할 항목을 말함 |

실패 테스트 지시문(그대로 붙여넣기)은 각 모듈 `03_tests/test_failure.md`에, "안 되면" 되묻기와 부분 통과 판정은 같은 폴더의 `test_*.md`에 있습니다.
