# 도구 실행 예산 — 횟수 제한이 있습니다

사내 도입 환경은 기능별 월 실행 횟수가 정해져 있습니다(8/18 안내 기준 약 10회/월). 실습 중 소진되면 남은 모듈을 못 하므로 **모듈별 실행 횟수를 미리 정해두고** 시작합니다.

## 왜 Instant·Flash로 충분한가

이 과정의 품질은 **모델의 추론 길이가 아니라 IPO와 참조 파일의 정확도**에서 나옵니다.

- 자료를 붙여주면 → 추론할 게 줄어듭니다
- 처리 순서를 지시문에 쓰면 → 모델이 순서를 고민하지 않습니다
- 출력 서식을 고정하면 → 형식 생성에 토큰을 쓰지 않습니다

즉 IPO를 제대로 쓴 Instant가, IPO 없이 돌린 Pro보다 재현성이 높습니다.

## 양성과정 참가자 주의 (9/16~17 → 10월 본 과정)

양성과정에서 Deep Research·에이전트 실행을 쓰면 **같은 계정의 월 한도가 줄어듭니다.** 10월 본 과정에서 사내강사로 진행할 때 실행 횟수가 부족할 수 있습니다.

대응:
- 양성과정에서는 Deep Research를 실제 실행하지 않고 팩의 `handoff/customer_profile.md`로 대체합니다. 실행 화면은 강사 시연으로 봅니다.
- 에이전트 실행은 양성과정 1회, 본 과정 준비 리허설 1회로 나눠 씁니다.

## 실행 전 확인

```
□ 이번 모듈에서 내가 쓸 실행 횟수는 몇 회인가
□ 실행 전에 참조 파일을 다 올렸는가 (올리다 말고 실행하면 1회 낭비)
□ 지시문 7블록을 다 채웠는가
□ 실패하면 무엇을 고쳐 재실행할지 정해뒀는가
```

한 번의 실행을 낭비하지 않는 가장 확실한 방법은 **실행 전에 IPO를 완성하는 것**입니다.
