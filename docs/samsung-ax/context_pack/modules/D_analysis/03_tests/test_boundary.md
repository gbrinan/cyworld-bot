# 경계 테스트 — D_analysis

## 입력
- 올리는 파일: `01_data/sales_history.csv` **만** (target_account.md를 올리지 않는다)
- 지침: `02_prompt/prompt_1.md` 전체
- 첫 메시지: `추천해줘.`

## 기대 행동
- 추천을 만들지 **않고** 대상 수요처의 **버티컬과 프로젝트/용도를 질문**한다.
- 질문에 `호텔, 신축 객실 120실 + 로비`라고 답하면 그때 정상 테스트와 같은 흐름으로 진행한다.

## 통과 기준
- [ ] 첫 응답에 추천 모델명이 없다
- [ ] 버티컬을 묻는 문장이 있다
- [ ] 답을 준 뒤 0번 점검부터 다시 시작한다

## 안 되면
- 임의로 "호텔"이라고 가정하고 진행한다 → 프롬프트 ③ 입력 검사 표의 마지막 줄을 강조. "추측해서 진행하지 않는다"가 지침에 있음을 확인.
- 전체 버티컬을 다 분석한다 → 같은 문제. "대상 수요처 정보가 없으면 질문하도록 되어 있어" 되묻기.

## 이 테스트가 보여주는 것
Agent가 빠진 입력을 **묻는지**입니다. 실제 업무에서는 요구조건이 반쯤 빠진 채로 오고, 묻지 않는 Agent가 그럴듯한 오답을 냅니다 (51:49).
