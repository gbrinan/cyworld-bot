# 정상 테스트 — E_supplier

## 입력
- 올리는 파일: `01_data/quotes.csv`, `01_data/supplier_history.csv`, `01_data/purchase_request.md`
- 지침: `02_prompt/prompt_1.md`의 ✂ 사이 (또는 `07_skill/SKILL.md` 등록)
- 첫 메시지: `파일 3개를 올렸어. 지침 순서대로 견적 비교를 만들어줘.`

## 기대 행동
1. 요청 품목이 아닌 **18건 제외**가 보고된다. 남은 6곳으로 판정한다.
2. **결격 판정이 비교표보다 먼저** 나온다.

| 공급사 | 분류 | 걸린 값 vs 기준 |
|---|---|---|
| 신우산업 | 결격 | 두께 1.8mm < 2.0mm |
| 동진테크 | 결격 | 최소주문 3,000개 > 필요 2,000개 |
| 제일전자 | **재견적 필요** (결격 아님) | 견적일 2026-05-15, 120일 경과 > 90일 |

3. 비교표에 **대광상사·성진물산·한백금속** 세 곳만 남는다.
4. 추천이 아래와 같다.

| 순위 | 공급사 | 총액 | 예산 대비 | 납기 |
|---|---|---|---|---|
| 1 | 성진물산 | **20,800,000** | 86.7% | 15일 |
| 2 | 한백금속 | **22,400,000** | 93.3% | 10일 |

5. **최저 단가가 1순위가 아닌 이유**가 적힌다.
   - 최저 단가는 신우산업 9,600원이지만 **규격 미달로 결격**
   - 발주 가능한 곳 중 최저는 대광상사 19,600,000원이지만 **납기 25일(희망 20일 초과)·준수율 71%·품질이슈 3건**
6. **순위 판단의 두 조건 계산값이 적힌다.**
   - 총액 차이 1,600,000원 = 낮은 쪽 20,800,000의 **7.7%** → 10% 이내, 조건 충족
   - 납기준수율 차이 96% vs 97% = **1%p** → 5%p 미만, 조건 미충족
   - **둘 다 충족해야 뒤집으므로 총액이 낮은 성진물산이 1위.** 한백금속을 1위로 올리면 실패다.
7. 제일전자가 **비교표에 없고** 5절에 재견적 요청 항목으로 올라간다.

## 통과 기준
- [ ] 결격 판정이 비교표보다 먼저
- [ ] 결격 2곳 + 재견적 1곳이 정확히 분류된다 (제일전자를 결격으로 쓰면 부분 통과)
- [ ] 비교표에 세 곳만 있다
- [ ] 1순위 성진물산 20,800,000 (한백금속이면 실패)
- [ ] 두 조건 계산값(7.7% / 1%p)이 본문에 있다
- [ ] 제일전자가 비교표에 없다
- [ ] 최저가가 1순위가 아닌 이유가 한 줄로 있다
- [ ] 단가를 깎은 금액이 어디에도 없다

## 안 되면
- 싼 순으로 줄부터 세운다 → 지침 ④-2 "결격 사유를 먼저 판정한다"를 다시 읽게 한다.
- 제일전자를 결격에 넣는다 → "유효기간 경과는 결격이 아니라 재견적 필요로 따로 분류해줘".
- 대광상사를 1순위로 올린다 → "희망납기를 충족하는 곳을 우선한다"를 확인. 준수율 71%도 함께 짚는다.
