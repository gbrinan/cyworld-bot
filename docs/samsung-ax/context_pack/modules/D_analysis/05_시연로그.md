# 시연 로그 — D_analysis

> 도입 15분 시연은 이 순서 그대로 진행합니다.
> 실행 기록: **미실행** — 삼성 계정(ChatGPT 에이전트 · 코드 실행 켜짐 / Gemini)에서 실행 후 "실제 대화" 표를 채웁니다.
> 아래 기대 응답은 `04_기준본/대시보드.html` · `04_기준본/리뷰.md`(데이터에서 직접 계산한 기준본) 기준입니다.

## 올린 파일
1. `01_데이터/매출데이터.csv` (1,093행, 16열, 2025-01-02 ~ 2026-09-24)
2. `01_데이터/매출데이터_소계.csv` (27행 — 다섯 축 + 전체)

## 붙여넣은 프롬프트
`02_지시문/지시문_1_대시보드.md`의 `✂` 사이. 클릭 경로: 사이드바 [에이전트] → [만들기] → [지침]에 붙여넣기 → [파일 업로드] 2개 → 저장. **코드 실행이 켜져 있어야 합니다.**

## 첫 메시지
```
매출데이터와 소계 파일을 올렸어. 0번 점검부터 하고 이상 없으면 대시보드까지 만들어줘.
```

## 첫 응답에서 확인할 것
- [ ] "0번 점검"이 화면보다 **먼저** 나오는가
- [ ] 소계 다섯 축이 **전부 일치**하고 전체 합계 **8,623,580,000원**인가
- [ ] **단가 열이 없어 검산식을 세울 수 없다**는 사실을 적는가
- [ ] 9월은 **1~24일**로, 8월 · 작년 9월도 **1~24일**로 잘라 견주는가 (전월 동기간 +2.8% · 전년 동월 동기간 −46.9%)
- [ ] 피벗 행을 누르면 **걸러지고 한 단계 내려가는가**

## 안 나오면 되묻는 문장
```
비교는 전부 같은 날짜까지 자른 기간으로 해줘. 9월이 24일까지면 8월도 작년 9월도 24일까지만.
그리고 소계 파일과 다섯 축을 표로 대조한 결과를 맨 위에 보여줘.
```
그래도 합계가 다르면 → 코드 실행이 꺼진 것입니다. 도구 설정을 확인합니다. 붙여넣기본으로는 일별 · 판매처 화면이 나오지 않습니다.

## 참가자에게 짚어줄 한 문장
"9월이 8월보다 40% 빠진 것처럼 보이는 숫자, 같은 날짜까지 자르면 +2.8%입니다. **비교는 동기간으로.**"

## 시연 중 보여줄 두 번째 장면 — 임원의 "왜" (3분)
'왜 이렇게 됐나'에서 **전년 동월 · 수요처**로 두고, 미래로병원 116%를 보여줍니다. 그 아래 **작년 쪽 큰 건 4건**(노트북 일괄 교체)을 가리킵니다.
"원인이 올해가 아니라 작년에 있었습니다. 이걸 **기저효과**라고 합니다. 이 네 건을 빼면 전년비는 −1.9%입니다."

## 시연 중 보여줄 세 번째 장면 — 보직장의 드릴다운 (2분)
피벗에서 **판매처 → 가야네트웍스**를 누르고 → 수요처 → 품목구분으로 내려갑니다. 화면 위 칩이 쌓이는 것과, ✕로 푸는 것을 보여줍니다.
그다음 '판매처가 맡은 수요처' 표에서 **한울종합건설을 대리점 두 곳이 같이 맡는다**는 표시를 가리킵니다.

## 시연 중 보여줄 네 번째 장면 (2분, 시간 되면)
실패 테스트를 즉석에서: `03_테스트/매출데이터_함정.csv`로 바꿔 올려 **0번에서 멈추는지** 확인.
멈추면 "지금 이게 성공입니다"를 꼭 말합니다. 참가자 절반이 이걸 실패로 받아들입니다.
