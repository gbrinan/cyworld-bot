> 삼성 양식 3 · SKILL 이름 `recommending-products-by-vertical` · 모든 데이터는 가상

## 1. 지금은 이렇게 일합니다
신규 수요처에 제품을 제안하려면 과거 판매 실적 엑셀을 열어 같은 업종(버티컬) 고객이 무엇을 샀는지 필터하고, 어떤 조합이 반복됐는지 눈으로 찾습니다. 실적이 수백 행이면 반나절이 가고, "왜 이 제품인가"를 근거 수치로 설명하는 자료는 따로 만들어야 합니다.

## 2. 오늘 만들 결과물
`recommend_D.html` — 브라우저에서 열리는 보고서 1개. 절 순서: 0. 데이터 점검 → 1. 대상 수요처 분석 → 2. 버티컬별 판매 Insight → 3. 추천 제품 TOP 3 (근거 행 번호 포함) → 4. 영업 제안 Point. 기준본은 `04_answer/recommend_D.html`.

## 4. 이 데이터의 함정
- 호텔 22행이 전체 금액의 3분의 2입니다. 호텔이 아닌 버티컬의 큰 금액(상업시설 미디어월 등)에 끌려가면 안 됩니다.
- 스탠드(ST-H1)는 단가가 작아 금액 순으로 보면 5위 밖입니다. **수량과 동반 구매**로 봐야 2위가 됩니다.
- 대상 수요처는 실적에 없는 "신규"지만 같은 체인의 다른 지점이 있습니다. 이걸 찾는지가 1절의 포인트입니다.

## 5. 도구와 클릭 경로
