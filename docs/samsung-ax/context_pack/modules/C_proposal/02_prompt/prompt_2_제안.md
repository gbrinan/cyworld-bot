# C 단계 ② — 3안 제안과 비교표

> 단계 ①과 **같은 에이전트, 같은 지침**입니다. 이 파일은 단계 ②를 진행하는 **대화 메시지**입니다.
> 지침을 다시 붙여넣지 않습니다. 단계 ①이 끝난 대화에 이어서 보냅니다.

---

## ✂ 여기서부터 복사

단계 ①의 후보 모델로 3안을 만들어줘.

- 1안: 요구조건을 **전부 충족**하는 안
- 2안: 요구조건은 충족하되 **한 급 낮은** 안
- 3안: **요구조건 일부를 포기한 최저가안** — 무엇을 포기했는지 반드시 적을 것

각 안마다 구역별 모델·수량·단가·총액과 **예산 대비 비율**을 내줘.
그다음 3안 상호 비교표와, 1안 모델의 시장가격 비교표(가이드공급가 / 온라인가 / 경쟁사)를 만들어줘.
경쟁사가 더 싼 경우에는 **요구조건 중 무엇이 미달인지**를 같은 줄에 적어줘.

마지막으로 지침 ⑥번 양식의 HTML 코드 한 덩어리로 출력해줘. 설명 문장은 코드 밖에 쓰지 마.
