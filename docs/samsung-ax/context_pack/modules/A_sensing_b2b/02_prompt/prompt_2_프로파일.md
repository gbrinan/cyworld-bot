# A 단계 2 — Customer Profile (묻는 것이 기능인 단계)

> **다른 단계와 반대입니다.** 여기서는 Agent가 **먼저 묻습니다.**
> 아는 것을 먼저 붙여넣으면 빠진 항목만 묻습니다.

---

## ✂ 여기서부터 복사

지금부터 신규 수요처의 Customer Profile을 만든다. **네가 질문하고 내가 답한다.**

**진행 방식**
1. 내가 아는 정보를 먼저 붙여넣을 수 있다. 붙여넣으면 **채워진 항목은 다시 묻지 않고 빈 항목만 묻는다.**
2. 아무것도 주지 않으면 **회사명부터 하나씩 묻는다.**
3. **한 번에 하나씩 묻는다.** 여러 질문을 한꺼번에 던지지 않는다.
4. 내가 "모른다"고 답하면 그 항목을 `확인 필요`로 비워 두고 **다음 질문으로 넘어간다.** 추정해 채우지 않는다.
5. 항목이 다 끝나면 프로파일을 출력하고, **비어 있는 항목과 그것을 누구에게 물으면 되는지**를 마지막에 적는다.

**물어볼 항목 (순서대로)**
| # | 질문 | 모르면 |
|---|---|---|
| 1 | 회사명과 상장 시장 (코스피·코스닥·코넥스·비상장) | 공시 사이트에서 확인 필요로 표기 |
| 2 | 주력 공종 (주택·상업시설·호텔·물류·오피스·토목·플랜트) | 확인 필요 |
| 3 | 최근 수주·착공한 현장이 있는가. 있으면 현장명과 시기 | 확인 필요 (수집 결과로 채울 수 있음) |
| 4 | 우리와 거래 이력 (신규 / 기존 / 과거 거래 후 중단) | 확인 필요 |
| 5 | 사내에 이 회사 접점이 있는가 (누가 아는가) | 확인 필요 — 팀장에게 질문 |
| 6 | 왜 지금 이 회사인가 (무엇을 보고 후보에 넣었는가) | 확인 필요 |

**출력 형식**

```
# Customer Profile — {회사명}
작성일 {날짜} · 작성자 {이름} · 근거 {rss_feed.csv 몇 행 / 사람 답변}

## 기본 정보
회사명 · 상장 시장 · 주력 공종

## 주력 공종과 최근 수주
현장명 · 시기 · 규모 (근거: 몇 행 또는 "담당자 답변")

## 거래 이력
신규 / 기존 / 중단. 중단이면 사유

## 접점
누가 아는가. 없으면 "없음"

## 모르는 것
| 항목 | 누구에게 물으면 되나 |
```

**하지 않는 일**
- 회사 규모·매출·신용도를 추정하지 않는다
- 담당자 이름·연락처를 적지 않는다
- 내가 답하지 않은 항목을 채우지 않는다

## 대화 시작 예시

1. `신규 후보 회사를 프로파일로 정리하고 싶어. 질문해줘.`
2. `한울종합건설, 코스닥, 호텔·상업시설까지는 알아. 나머지를 물어봐.`
3. `rss_feed.csv를 올렸어. 여기서 채울 수 있는 항목은 채우고 나머지만 물어봐.`
