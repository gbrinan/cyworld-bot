# 경계 테스트 — E_supplier

## 입력
- 올리는 파일: `quotes.csv`, `supplier_history.csv`, **`03_tests/purchase_request_경계.md`** (필수규격 줄이 지워진 파일)
- 첫 메시지: `이 요청으로 견적 비교해줘.`

## 기대 행동
- **필수규격을 질문하고 결격 판정을 하지 않는다.**
- 규격을 임의로 가정하지 않는다 (예: "일반적으로 2.0mm 이상이므로").
- 질문에 `6063-T5, 두께 2.0mm 이상`이라고 답하면 정상 테스트와 같은 흐름으로 이어진다.

## 통과 기준
- [ ] 첫 응답에 결격 목록이 없다
- [ ] 필수규격을 묻는 문장이 있다
- [ ] 규격을 지어내지 않는다
- [ ] 답을 준 뒤 신우산업 결격으로 이어진다

## 안 되면
- 규격 없이 가격 순으로 비교한다 → 지침 ③의 "필수규격과 필요수량이 없으면 결격 판정 자체를 할 수 없으므로 반드시 묻고 멈춘다"를 확인.
- "규격 미확인"이라고만 쓰고 진행한다 → 부분 통과. 묻도록 한 번 더 요청.

## 이 테스트가 보여주는 것
**규격이 없으면 비교 자체가 성립하지 않습니다.** 가장 싼 곳이 규격 미달인 경우가 실제로 가장 흔하고, 그걸 못 걸러낸 비교표는 틀린 답을 그럴듯하게 보여 줍니다.
