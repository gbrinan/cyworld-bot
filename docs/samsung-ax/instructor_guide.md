## 0. 진행 원칙

**실제 자동 연결보다 IPO·중단 조건·테스트 행동을 먼저 완성하게 합니다.
실패 데이터에서 멈추면 성공한 실습입니다.**

강사가 지켜야 할 네 가지.

1. **팩을 열게 합니다.** 참가자가 자기 기억으로 프롬프트를 쓰기 시작하면 멈추고 파일을 올리게 합니다.
2. **진도보다 체인을 지킵니다.** 못 끝낸 참가자는 각 모듈 `04_기준본/` 기준본으로 다음 모듈을 시작하게 합니다. 뒤처졌다고 다음 실습을 못 하게 두지 않습니다.
3. **실행 횟수를 아낍니다.** 도구 실행 전에 분해표와 파일이 준비됐는지 확인합니다. 빈손으로 실행하면 1회가 날아갑니다.
4. **답을 주지 않고 되묻습니다.** `common/review_criteria.md`의 되묻는 질문 목록을 씁니다.

- (실습 2·3) "참고용"이라며 할인 금액을 계산해 주면 — 실패입니다. ⑥ 금지 문장을 ⑦ 성공 기준에도 넣습니다

**검수 5분에서 볼 것** — ① 3안의 포기 항목이 적혔는가 ② 경쟁사가 싼 줄에 미달 항목이 있는가 ③ 가이드공급가가 제안가로 둔갑하지 않았는가.

**전환 질문** — 내가 받는 요구조건에서 반쯤 빠지는 항목은 무엇인가? 그걸 Agent가 묻게 하려면 ③에 뭐라고 써야 하나?

자세한 되묻기와 부분 통과 판정은 `modules/C_proposal/03_테스트/테스트_*.md`의 "안 되면" · "부분 통과와 실패" 표.

## 4. 보조강사 운영 (3명, 차수당 40~50명)

| 구간 | 보조강사 역할 |
|---|---|

| 실습 3 | 실패 테스트에서 멈췄는지 확인. 안 멈춘 참가자는 지시문 ⑥으로 유도 |

## 6. 자주 나오는 상황 대응

| 상황 | 대응 |
|---|---|
| 실행 횟수를 다 씀 | `04_기준본/` 파일로 진행. 실행 화면은 강사 시연으로 보여줌 |
| **파일 업로드 버튼이 없음** | `06_붙여넣기/` 폴더의 마크다운 표를 복사해 붙여넣게 함. "아래는 첨부 자료입니다" 한 줄 먼저 |
| **한글이 깨짐** | `06_붙여넣기/` 표로 전환 |
| **AI가 만든 파일이 다운로드 안 됨** | 정상입니다. 화면 출력을 복사해 메모장에 저장하게 함 |
| **새로고침하니 지시문이 사라짐** | 메모장에 보관한 지시문을 다시 붙여넣게 함. 안 만들어 뒀으면 `02_지시문/`에서 다시 복사하게 함 |
| **D에서 합계가 매번 다름** | 코드 실행이 안 되는 것. **소계본 + 호텔모델별 집계본 둘로 교체 (소계본만 올리면 추천이 안 나옵니다)**하고 한 개를 직접 검산시킴 |
| 도구가 파일을 못 읽음 | 파일을 하나씩 올리게 함. CSV는 인코딩 문제일 수 있으니 팩 원본을 다시 받게 함 |
| 결과가 매번 다름 | 지시문에 출력 형식이 고정되어 있는지 확인. "형식을 고정하면 편차가 줄어듭니다" |
| "그냥 GPT로 하면 안 되나요" | 됩니다. 다만 오늘은 **팀이 바뀌어도 재사용되는 형태**를 만드는 게 목표라고 설명 |
| 실제 업무 파일을 올리려 함 | **즉시 제지.** `security_rules.md` 안내 |
| 진도가 크게 뒤처짐 | 최소 완주 라인만 채우게 하고 다음 모듈로 넘김 |
