# 담당 구역 기회 대시보드 — 채운 예시

> `dashboard_territory.md`의 `채우는 칸`을 **2교시 B 실습 데이터로 채워 본 것**입니다.
> 수치는 `modules/B_sensing_partner/01_데이터/`에서 그대로 재현됩니다. **함정 파일(`파트너정보_실패.csv`)은 쓰지 않았습니다.**

## 채우는 칸

| 자리표시자 | 채운 값 |
|---|---|
| `{{팀명}}` | B2B유통전략팀 |
| `{{구역}}` | 부산 해운대 |
| `{{기회 파일}}` | `뉴스수집.json` (30건) |
| `{{대조 파일}}` | `상권정보.csv` (18행) |
| `{{배정 파일}}` | `파트너정보.csv` (4곳) |
| `{{유형 열}}` | 시설유형 |
| `{{규모 열}}` | 규모 |
| `{{규모 하한선}}` | 객실 50실 · 연면적 3,000㎡ · 병상 50 |
| `{{시기 열}}` | 예정시기 |
| `{{배정 조건}}` | 담당권역 · 주력버티컬 · 시공가능규모 |
| `{{보는 사람}}` | 팀장, 파트너 미팅 |

## 이렇게 나옵니다

### 구역 흐름

```
뉴스 30건 → 해운대 18건 / 타 권역 12건 제외
상권정보 18행 시설유형 분포 : 상업시설 6 · 병상(병원) 4 · 호텔 3 · 교육시설 3 · 오피스 2
```

하한선을 넘은 건만 기회 목록으로 가고, 미달 건은 **버리지 않고 세어서** 이 절의 근거가 됩니다.
"이번 분기 미달 건 n건"이라는 한 줄이 큰 건 하나보다 구역 분위기를 더 잘 말해 줍니다.

### 기회 목록

예정시기가 가까운 순입니다. 각 줄에 담당 파트너가 붙습니다.

파트너는 네 곳입니다. 남해정보통신 · 동백시스템 · 가야네트웍스 · 빛고을솔루션.
세 조건을 **모두** 만족해야 붙습니다. 담당권역이 해운대를 포함하고, 주력버티컬이 시설유형과 같고, 시공가능규모가 건의 규모 이상이어야 합니다.

### 담당 미정

**조건이 안 맞으면 억지로 붙이지 않고 여기로 보냅니다.** 그리고 어느 조건이 왜 안 맞는지 파트너별로 적습니다.

단위가 다른 경우가 자주 나옵니다. 시공가능규모가 객실 수로 적혀 있는데 대상이 연면적이면 **환산하지 않고 조건 불충족**으로 봅니다.
사유에는 양쪽 단위를 같이 적습니다. `담당 없음 — 단위 불일치 (시공가능 객실 단위 / 대상 연면적)`처럼요.

이 블록이 비어 있지 않은 게 정상입니다. **여기가 다음 분기에 파트너를 늘릴지 결정하는 근거**입니다.

## 파트너 영업이 아니어도 씁니다

`파트너`를 `담당자`로 바꿔 읽으면 그대로 돌아갑니다.

| 원래 자리 | 바꿔 쓰는 예 |
|---|---|
| 담당 파트너 | 담당 영업사원 · 담당 대리점 · 담당 채널 |
| 담당권역 | 담당 지역 · 담당 산업군 · 담당 계정군 |
| 시공가능규모 | 담당 가능 규모 · 처리 가능 건수 |

배정할 사람이 **한 명뿐이면 6·7번 단계를 빼고** 기회 목록까지만 쓰십시오. 조건 표가 한 줄이면 표일 필요가 없습니다.

## 이 예시에서 배울 것 셋

**하나. 하한선 아래를 버리지 않습니다.** 기회 목록에서는 빼되 건수로 남깁니다. 작은 건의 증감이 구역의 신호입니다.

**둘. 단위가 다르면 환산하지 않습니다.** 객실 수와 연면적을 임의로 바꾸는 순간 아무도 그 숫자를 못 믿습니다.

**셋. 담당 미정 블록이 보고 대상입니다.** 비워 두려고 억지로 붙이면, 결국 아무도 안 하는 건이 쌓입니다.
