## ✂ 여기서부터 복사

아래는 내가 웹 화면에서 복사한 텍스트다. 광고·배송비·리뷰수·판매자 홍보문구가 섞여 있다.

다음 규칙으로 표 하나만 만들어라.
- 열은 정확히 이 네 개다: 수요처명 | 모델명 | 온라인가격 | 제품spec.
- 수요처명에는 판매처(쇼핑몰) 이름을 넣는다
- 온라인가격은 숫자만 넣는다 (원, 콤마, "최저가" 같은 말 제거)
- 제품spec.에는 화면에 실제로 적힌 사양만 넣는다 (인치·해상도·밝기·포트)
- **화면에 없는 값은 비워 두고 "확인필요"라고 적는다. 추정해서 채우지 않는다**
- 스펙은 제조사 공식 정보만 넣는다. 판매자가 쓴 설명에서 가져온 값이면 "판매자기재"라고 표시한다
- 같은 모델이 여러 번 나오면 한 줄로 합치고 가격은 최저값을 쓴다
- 판매자 이름·연락처·사업자번호는 표에 넣지 않는다
- 온라인가격 옆에 조회 조건을 적는다. 예) 729,000 (비회원가)
- 표 아래에 조회 날짜 한 줄을 적는다
- 마지막에 쉼표로 구분된 CSV 형태로도 한 번 더 출력한다
