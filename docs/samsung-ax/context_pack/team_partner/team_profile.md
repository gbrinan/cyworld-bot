# B2B유통전략팀 (파트너 관리영업) 프로필

> 출처: 김승진 프로 메일 「교육대상 - B2B팀, B2B유통전략팀」(2026-09-04)
> 용도: ②③④ Agent 모두의 참조 파일. GPT 프로젝트 파일 / NotebookLM 소스 / Gemini 에이전트 참조 파일로 업로드합니다.

## 1. 담당 경로

- B2B팀 대비 **규모가 작은 수요처**를 담당합니다. SMB 시장 — 중소기업, 소상공인, 협회 등.
- 그래서 당사가 직접 수요처를 영업하는 경우가 많지 않고, **B2B 파트너가 담당**합니다. (매장점이 아닌 일반 사무실점이 다수)
- 파트너가 영업을 하므로 당사는 **파트너 관리에 집중**합니다. 매출 관리, 판매정책 공유 등.
- B2C 파트너(삼성스토어처럼 제품을 진열하고 고객이 찾아오는 형태)가 **아닙니다.**

## 2. 주요 품목

- 전 품목을 담당합니다.
- 매출 규모는 **SAC**가 큰 편입니다.

## 3. 주요 관리 항목

| 항목 | 내용 |
|---|---|
| 복지몰 공략 | 수요처들의 복지몰 (추석선물, 창립기념일 선물 등) |
| 대형 파트너 매출 관리 | 상위 파트너 실적 집중 관리 |
| 구독 비즈니스 | 월 단위 과금 구독 |
| DMFP 유지보수 | 복사기 유지보수 비즈니스 |

## 4. Agent 설계에 주는 의미

| 관리 항목 | Agent에서 어떻게 쓰이나 |
|---|---|
| 파트너가 영업 | ③ Action의 제안서 독자는 최종 고객이 아니라 **파트너**일 수 있습니다. 독자를 반드시 지정합니다 |
| SMB 대상 | ② Sensing은 개별 고객사가 아니라 **업종·지역 세그먼트** 단위로 봅니다 |
| 복지몰 시즌성 | ② ④ 모두 **시즌(명절·창립기념일)** 기준 기간 설정이 중요합니다 |
| 구독 비즈니스 | ④ Analysis에서 매출만이 아니라 **구독 건수와 해지 건수**를 함께 봅니다 |
| DMFP 유지보수 | 단발 판매가 아닌 **월 과금**이므로 누적·해지 관점으로 분석합니다 |

## 5. 이 팀의 Agent가 흔히 틀리는 것

- 개별 고객사 단위로 분석한다 → SMB는 세그먼트 단위로 봐야 의미가 있습니다
- 제안서 독자를 최종 고객으로 잡는다 → 실제 독자는 파트너인 경우가 많습니다
- 구독 매출을 단발 매출과 같이 합산한다 → 해지율이 안 보입니다
- 파트너 등급(A/B/C)을 무시하고 절대 매출만 본다 → 등급별 관리 방침과 어긋납니다
- 경쟁사 프로모션을 가격만 비교한다 → 파트너몰/온라인몰 **채널별**로 조건이 다릅니다
