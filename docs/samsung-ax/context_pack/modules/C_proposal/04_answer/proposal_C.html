5. 확인 필요 사항

  1. 제안 가격 — 가이드공급가는 참고값입니다. 6대 기준 조건은 담당자가 확정합니다
  2. 온라인가 조회 시점 — 크롤 표에 일자 열이 없어 미상입니다. 재조회 후 날짜를 붙여야 합니다
  3. MX-80P 시장가 미확인 — 2안 대회의실 모델입니다. 추가 조회가 필요합니다
  4. 납기 — 고객 희망 2026년 11월. 재고와 리드타임 확인 필요
  5. 설치 — 벽걸이 브래킷·전원·배선 별도. 현장 실측 필요
  6. 경쟁사 스펙 — 판매자 기재분입니다. 무선 화면공유 표기 없는 항목은 제조사 자료로 확인
  7. 대회의실 화면크기 — 80인치(2안)와 85인치(1안) 중 시야거리 실측으로 결정
  8. HX·KX 계열의 HDMI 포트 수 — 가이드에 열이 없어 확인불가로 처리했습니다
