# 공통 검수 기준

Agent가 만든 결과물을 사람이 5분 안에 검수하는 체크리스트입니다. 세 Agent 모두 같은 기준을 씁니다.

## 5분 검수 체크리스트

| # | 항목 | 확인 방법 | 불합격이면 |
|---|---|---|---|
| 1 | 근거 없는 수치 0건 | 숫자마다 근거 파일·행이 붙어 있는가 | 지시문 ⑤에 근거표 필수 추가 |
| 2 | 필수 항목 100% | 서식의 모든 칸이 채워졌거나 "확인 필요"로 표시됐는가 | 지시문 ③에 필수 입력 목록 추가 |
| 3 | 개인정보 재출력 0건 | 실명·연락처·계정이 결과물에 없는가 | 지시문 ⑥에 가명화·중단 규칙 추가 |
| 4 | 확정 문구 0건 | 가격·납기·할인·SLA가 확정형으로 쓰이지 않았는가 | 지시문 ⑥에 확정 문구 금지 추가 |
| 5 | 승인 칸 공란 | 서명·결재 칸을 AI가 채우지 않았는가 | 지시문 ⑦에 승인자 명시 |
| 6 | 인계 가능 | 다음 Agent가 쓸 파일로 저장됐는가 | 출력 형식에 파일 저장 단계 추가 |

**1·3·4번은 안전 항목입니다.** 나머지가 모두 통과해도 이 셋 중 하나가 걸리면 결과물을 쓰지 않고 지시문을 고칩니다.

## 등급

| 등급 | 조건 | 다음 행동 |
|---|---|---|
| 사용 가능 | 6개 전부 통과 | 사람 승인 요청 |
| 보완 필요 | 안전 항목 통과, 나머지 1~2개 미달 | 해당 지시문 블록만 수정 후 재실행 |
| 재작성 | 안전 항목 중 하나라도 미달 | 결과물 폐기, 지시문 ⑥ 재작성 |

## 흔한 오류와 되묻는 질문

| 관찰된 오류 | 참가자에게 되묻는 질문 |
|---|---|
| "정확하게 작성해줘"처럼 기준이 추상적 | 몇 건, 몇 %, 어떤 상태면 통과인가요? |
| 없는 값을 그럴듯하게 채움 | 근거가 없을 때 어떤 문구를 남기고 어디서 멈추나요? |
| 테스트가 정상 데이터뿐 | 합계가 틀린 파일과 실명이 든 파일이 오면 어떻게 행동하나요? |
| 승인자 미지정 | 누가 무엇을 확인한 뒤 고객에게 보내나요? |
| 출력이 화면에만 있음 | 다음 Agent는 이 결과를 어떤 파일로 받나요? |
