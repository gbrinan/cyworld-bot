# 정상 테스트 — D_analysis

## 입력
- 올리는 파일: `01_데이터/매출데이터.csv`, `01_데이터/매출데이터_소계.csv`
- 지침: `02_지시문/지시문_1_대시보드.md`의 `✂` 사이
- 첫 메시지: `매출데이터와 소계 파일을 올렸어. 0번 점검부터 하고 이상 없으면 대시보드까지 만들어줘.`

## 기대 행동 — 1단계 대시보드

1. **0번 점검이 화면보다 먼저** 나온다. 54행, 기간 2026-01-04 ~ 2026-09-27.
2. 소계 대조 — 품목구분 · 주문유형 · 수요처명 **세 축 모두 일치**. 전체 합계 **571,220,000**.
   **단가 열이 없어 검산식을 세울 수 없다는 사실**을 「확인 필요」에 적는다.
3. 한눈에 — 571,220,000 / 54건 / 건당 10,578,148 / 2026-Q2 222,160,000 (−5.2%, Q1 234,260,000).
4. 어디서 나왔나 — 세 축 표. 품목구분 상위 2개(사이니지 25.4% · PC 21.5%)가 **47%**.
   수요처명 상위 2개(대성건설 27.6% · 미래로병원 19.2%)가 **47%**.
   **주문유형처럼 값이 둘뿐인 축에 "상위 2개가 100%"를 쓰면 안 된다.**
5. 지난 기간과 견주면 — **2026-Q3을 비교에서 빼고** 그 이유를 적는다.
6. 눈에 띄는 것 — 사이니지 +73% · PC −64% · 모니터 +20%. 각각 **근거 행 번호**.
7. 필터 세 개(기간 · 조직 · 주문유형)가 **차트 위 한 줄**에 있고, 바꾸면 아래 숫자가 전부 다시 계산된다.

## 기대 행동 — 2단계 리뷰

같은 대화에 `02_지시문/지시문_2_분석.md`를 이어서 붙여넣는다. 기준본은 `04_기준본/리뷰.md`.

- 달라진 것 셋에 **비율과 금액이 둘 다**, **근거 행 번호**가 붙는다.
- PC 감소분의 대부분이 **미래로병원 한 곳**(37,380,000 → 0)이라는 것까지 간다.
- 쏠림은 숫자만 적고 **"쏠림이 문제"라고 쓰지 않는다.** 상위 2개가 47%로 50%를 넘지 않는다.
- **"알 수 없는 것" 세 개**가 있고 각각에 없는 열과 필요한 데이터가 적혀 있다.
- 전체가 A4 한 장 안에 들어간다.

## 통과 기준
- [ ] 0번 점검이 화면·글보다 먼저
- [ ] 소계 세 축 일치, 합계 571,220,000
- [ ] 단가 열이 없어 검산식이 없다는 사실이 적혀 있다
- [ ] 2026-Q3을 비교에서 뺐고 이유를 적었다
- [ ] 눈에 띄는 것마다 근거 행 번호
- [ ] 필터가 한 줄에 셋, 바꾸면 모든 숫자가 바뀐다
- [ ] 리뷰의 "알 수 없는 것"이 세 개이고 없는 열이 적혀 있다
- [ ] 원인이 적혔다면 전부 "가설"로 표시되고 확인 방법이 붙어 있다

## 안 되면
- 합계가 다르다 → 암산한 것. "소계 파일과 한 줄씩 대조해서 보여줘" 되묻기.
- Q3을 그대로 비교에 넣는다 → 지시문 ④3번 확인. 그대로 두면 "3분기 급감"이라는 **틀린 결론**이 나온다.
- 주문유형 축에 "상위 2개가 100%"가 나온다 → ④2번의 둘뿐인 축 단서 확인.
- 쏠림을 문제라고 단정한다 → 지시문 2의 ④3번 확인. 판단은 4번으로 넘기게 되어 있다.
