> 아래 기대 응답은 `04_기준본/대시보드.html`·`04_기준본/리뷰.md`(데이터에서 직접 계산한 기준본) 기준입니다.

## 올린 파일
1. `01_데이터/매출데이터.csv` (54행, 16열)
2. `01_데이터/매출데이터_소계.csv` (15행 — 품목구분·주문유형·수요처명 세 축 + 전체)

## 붙여넣은 프롬프트
`02_지시문/지시문_1_대시보드.md`의 `✂` 사이. 클릭 경로: 사이드바 [에이전트] → [만들기] → [지침]에 붙여넣기 → [파일 업로드] 2개 → 저장.

## 첫 메시지
```
매출데이터와 소계 파일을 올렸어. 0번 점검부터 하고 이상 없으면 대시보드까지 만들어줘.
```

## 첫 응답에서 확인할 것
- [ ] "0번 점검"이 화면보다 **먼저** 나오는가
- [ ] 소계 세 축이 **전부 일치**하고 전체 합계 **571,220,000원**이라고 말하는가
- [ ] **단가 열이 없어 검산식을 세울 수 없다**는 사실을 「확인 필요」에 적는가
- [ ] **2026-Q3을 분기 비교에서 뺐는가** (9월까지만 들어 있음)
- [ ] 눈에 띄는 것이 사이니지 +73% · PC −64% · 모니터 +20%이고 **근거 행 번호**가 붙는가
- [ ] 필터 세 개가 **차트 위 한 줄**에 있는가

## 안 나오면 되묻는 문장
```
소계 파일의 축별 합계와 네가 직접 더한 값을 한 줄씩 표로 비교해줘. 그다음 분기 비교에서 덜 찬 분기를 뺐는지 알려줘.
```
그래도 합계가 다르면 → 붙여넣기본(`06_붙여넣기/매출데이터.md`)으로 교체해 다시 올립니다 (코드 실행이 꺼진 환경의 암산 오류).

## 참가자에게 짚어줄 한 문장
"화면보다 점검이 먼저 나온 걸 보세요. 그리고 **단가가 없어서 검산을 못 한다**는 걸 숨기지 않고 적었습니다."

## 시연 중 보여줄 두 번째 장면 (3분)
필터를 **조직 = 경로1파트 + 주문유형 = 직판주문**으로 걸어 **0건**을 만듭니다.
0을 그리지 않고 "어느 필터를 풀면 되는지"를 적는지 확인합니다. 0원짜리 막대가 그려지면 그 자리에서 짚습니다.

## 시연 중 보여줄 세 번째 장면 (2분, 시간 되면)
실패 테스트를 즉석에서: `03_테스트/매출데이터_함정.csv`로 바꿔 올려 **0번에서 멈추는지** 확인.
멈추면 "지금 이게 성공입니다"를 꼭 말합니다. 참가자 절반이 이걸 실패로 받아들입니다.
