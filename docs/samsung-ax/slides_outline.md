## 제작 메모

- **꼬리표 4종(🔒✍️⚙️🔌)은 덱 전체에서 같은 기호·같은 색**으로 씁니다. 분해표와 지시문 슬라이드에 반복 등장합니다.
- **단계 박스는 항상 에이전트 테두리 안에** 넣습니다. 단계를 에이전트처럼 그리면 안 됩니다.
- 모든 모듈의 시간 배분이 같습니다. 모듈 표지마다 같은 타임바를 넣습니다.
- 수치와 모델명은 각 모듈의 `04_answer/` 기준본과 **반드시 일치**해야 합니다. 다르면 강사가 참가자 결과를 판정할 수 없습니다.
- 모든 데이터·회사명·가격은 **가상**입니다. 하단에 표기 자리를 둡니다.
