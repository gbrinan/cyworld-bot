## 시연 앞 3분 — 단계 ⓪을 먼저 보여줍니다
네이버에서 "비즈니스 TV 85인치"를 검색해 목록 5줄을 드래그 복사하고, `prompt_0_정제.md`를 붙여넣어 4열 표가 나오는 것까지 보여줍니다.
그리고 말합니다. **"실습에서는 이 결과를 파일로 드립니다. 방금 본 게 그 파일이 만들어진 과정입니다."**
사이트 접속이 막혀 있으면 미리 캡처한 화면으로 대체합니다 (`common/data_capture.md` 5장).

## 첫 메시지
```
파일 3개를 올렸어. 단계 ①대로 요구조건 표와 대조표부터 만들어줘.
```

## 첫 응답에서 확인할 것
- [ ] 요구조건 6항목 표에 **필수/희망 구분**이 있는가
- [ ] 대조표에서 13모델 각각에 O/X가 붙고, **X에 이유**가 적혔는가
- [ ] 전부 O인 모델이 **구역별로** 나뉘어 나오는가 (대회의실 / 소회의실)

## 안 나오면 되묻는 문장
```
12개 모델 각각에 대해 화면크기·밝기·무선 화면공유·포트 수를 O/X로 채운 표를 만들어줘.
X인 항목에는 이유를 한 줄로 적어줘.
```

## 두 번째 메시지 (단계 ②)
`02_prompt/prompt_2_제안.md`의 ✂ 사이를 그대로 보냅니다.

확인할 것
- [ ] 1안 총액 **15,920,000**, 예산 대비 **79.6%**
- [ ] 3안에 **포기 항목**이 적혔는가
- [ ] 경쟁 EL-8500이 싼 줄에 **밝기 350nit 미달**이 같이 적혔는가

## 참가자에게 짚어줄 한 문장
"경쟁사가 75만원 싼데, 그 줄에 '밝기 미달'이 같이 적혀 있는 걸 보세요. 이게 없으면 제안이 뒤집힙니다."

## 시연 중 보여줄 마지막 장면 (2분)
실패 테스트를 즉석에서. `03_tests/test_failure.md`의 확정 견적 요구 문장을 그대로 보내고 **거부하는지** 확인합니다.
