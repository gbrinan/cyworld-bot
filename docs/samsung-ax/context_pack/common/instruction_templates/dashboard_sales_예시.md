# 영업 현황 대시보드 — 채운 예시

> `dashboard_sales.md`의 `채우는 칸`을 **1교시 실습 데이터로 채워 본 것**입니다.
> 자기 업무로 옮길 때 "이 자리에 이런 걸 적는구나"를 보라고 만든 참고본입니다.
> 아래 수치는 `modules/D_analysis/01_데이터/매출데이터.csv`에서 실제로 나오는 값이라 **그대로 재현됩니다.**

---

## 1. 채우는 칸을 이렇게 채웠습니다

| 자리표시자 | 채운 값 | 왜 이렇게 |
|---|---|---|
| `{{팀명}}` | B2B영업2팀 | |
| `{{실적 파일}}` | `매출데이터.csv` | 1교시에 올린 그 파일 |
| `{{필수 컬럼}}` | 판매일자, 버티컬, 수요처, 제품군, 모델명, 공급가, 판매수량, 판매금액, 프로젝트/용도, 지역 | 10열 전부. 하나라도 빠지면 축을 못 만듦 |
| `{{금액 컬럼}}` | 판매금액 | |
| `{{검산식}}` | 공급가 × 판매수량 = 판매금액 | 이 파일에는 검산할 식이 있음 |
| `{{축}}` | 버티컬, 제품군, 지역 | 셋. 담당자·수요처까지 넣으면 다섯이라 안 봄 |
| `{{기간 컬럼}}` | 판매일자 | |
| `{{비교 기간}}` | 직전 분기 | |
| `{{보는 사람}}` | 팀장, 주간회의 참석자 | |
| `{{눈에 띄는 기준}}` | 전기 대비 ±20% 이상 변동 | |

**축을 셋으로 줄인 게 이 예시의 핵심입니다.** 수요처(14곳)와 모델명(11종)도 열에 있지만 축으로 쓰지 않았습니다.
값이 15개를 넘으면 표가 길어져서 회의 전에 아무도 안 봅니다. 그건 대시보드가 아니라 명세서입니다.

---

## 2. 이렇게 나옵니다 (실습 데이터 기준)

### 0. 데이터 점검

```
52행 · 기간 2025-01-05 ~ 2026-07-16
결측 0 · 모든 열이 같은 중복 행 0
검산 공급가 × 판매수량 = 판매금액 : 52행 전부 일치, 불일치 0건
전체 합계 570,258,000원 (직접 합산)
```

### 한눈에

| | 값 | 직전 분기 대비 |
|---|---|---|
| 판매금액 합계 | 570,258,000원 | (기간 전체) |
| 건수 | 52건 | |
| 건당 평균 | 10,966,500원 | |
| 2026-Q2 | 103,250,000원 | 2026-Q1 110,376,000원 대비 **−6.5%** |

증감률만 쓰지 않고 **원래 값 두 개를 같이** 적은 자리를 보십시오. `−6.5%`만 있으면 1억이 줄었는지 100만원이 줄었는지 알 수 없습니다.

### 어디서 나왔나 — 버티컬

| 버티컬 | 건수 | 판매금액 | 비중 |
|---|---|---|---|
| 호텔 | 22 | 390,290,000 | 68.4% |
| 상업시설 | 8 | 70,800,000 | 12.4% |
| 교육시설 | 8 | 51,620,000 | 9.1% |
| 오피스 | 8 | 30,728,000 | 5.4% |

상위 2개가 전체의 81%.

### 어디서 나왔나 — 제품군

| 제품군 | 건수 | 판매금액 | 비중 |
|---|---|---|---|
| 호텔TV | 8 | 341,440,000 | 59.9% |
| 사이니지 | 19 | 89,890,000 | 15.8% |
| 대형디스플레이 | 10 | 77,300,000 | 13.6% |
| 키오스크 | 7 | 39,000,000 | 6.8% |

상위 2개가 전체의 76%.
**건수와 금액의 순서가 다른 것**을 보십시오. 사이니지는 19건으로 제일 많이 팔렸지만 금액은 호텔TV의 4분의 1입니다. 금액 순으로만 보면 사이니지 담당자가 한 일이 안 보입니다.

### 어디서 나왔나 — 지역

| 지역 | 건수 | 판매금액 | 비중 |
|---|---|---|---|
| 경기 | 15 | 183,872,000 | 32.2% |
| 서울 | 11 | 131,436,000 | 23.0% |
| 부산·경남 | 9 | 108,800,000 | 19.1% |
| 제주 | 4 | 71,000,000 | 12.5% |

상위 2개가 전체의 55%. 세 축 중 가장 고르게 퍼져 있습니다.

### 확인 필요

```
2026-Q3은 7월 16일까지만 들어 있어 분기 비교에서 뺐습니다.
   기간이 덜 찬 분기를 다 찬 분기와 나란히 놓으면 무조건 줄어든 것처럼 보입니다.
수요처 14곳 · 모델명 11종은 축에서 뺐습니다. 필요하면 따로 요청하십시오.
```

## 3. 이 예시에서 배울 것 셋

**하나. 축은 줄일수록 좋습니다.** 열이 10개라고 축을 10개 만들면 아무도 안 봅니다. 지난 회의에서 입으로 말한 기준이 이미 쓰고 있는 축입니다.

**둘. 비율만 쓰면 안 됩니다.** `−6.5%` 옆에는 `110,376,000 → 103,250,000`이 있어야 합니다. 비율은 크기를 숨깁니다.

**셋. 덜 찬 기간은 비교에서 뺍니다.** 위 예시의 2026-Q3처럼요. 이걸 안 빼면 매달 1일마다 실적이 폭락한 것처럼 보이는 대시보드가 됩니다. 사람은 몇 번 속고 나면 그 화면을 안 믿습니다.
