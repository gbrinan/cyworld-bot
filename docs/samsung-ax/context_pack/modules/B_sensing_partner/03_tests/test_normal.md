# 정상 테스트 — B_sensing_partner

## 입력
- 올리는 파일: `naver_news_dummy.json`, `district_info.csv`, `partner_info.csv`, `market_research.md`
- 지침: `02_prompt/prompt_2_추출.md`의 ✂ 사이 (또는 `07_skill/SKILL.md` 등록)
- 첫 메시지: `파일 4개를 올렸어. 담당 권역은 부산 해운대야. 단계 1 검색 키워드부터 만들어줘.`
- 이어서: `prompt_3_보고서.md`의 ✂ 사이

## 기대 행동
1. 단계 1에서 조합 결과와 **뺀 조합의 이유**가 같이 나온다. (`04_answer/search_keywords.md` 참고)
2. **타 권역 12건 제외**가 보고된다 (대구 수성 6 · 광주 상무 6).
3. 기회 목록이 **3건**이다.

| 순위 | 시설명 | 규모 | 담당 파트너 |
|---|---|---|---|
| 1 | 해운대베이호텔 | 객실 200실 | 남해정보통신 |
| 2 | 마린그랜드호텔 | 객실 150실 | 남해정보통신 |
| 3 | 해운대제일고 | 연면적 8,400㎡ | **해당 파트너 없음** |

4. **규모 미달 6건**(카페 3 · 의원 2 · 학원 1)이 기회 목록에 없고, **1절 권역시장 요약에는 추세로** 남는다.
5. 3순위에 파트너가 안 붙고 **무엇이 부족한지**(부산·경남 파트너 중 교육시설 주력 없음) 적힌다.
6. 1·2순위 합계 350실이 남해정보통신 시공가능 200실을 **넘는다는 점**이 논의사항에 나온다.

## 통과 기준
- [ ] 타 권역 12건 제외 보고
- [ ] 기회 3건, 규모 미달 6건은 요약에만
- [ ] 3순위에 "해당 파트너 없음"과 부족 조건
- [ ] 시공가능규모 초과가 논의사항에 있다
- [ ] 5개 절이 순서대로 나온다

## 안 되면
- 카페·의원이 기회 목록에 올라온다 → "규모 하한선 아래 건은 기회 목록에서 빼고 1절 흐름으로만 써줘".
- 3순위에 남해정보통신을 붙인다 → **가장 흔한 실패.** "주력버티컬이 맞지 않는데 왜 붙였는지 설명해줘. 안 맞으면 해당 파트너 없음으로 써줘".
- 350실 초과를 지나친다 → `prompt_3_보고서.md` 아래 되묻는 문장을 보낸다.
