## 규칙

- **1280 × 720 고정.** 프레임은 줄어들지 않고 잘립니다. 내용을 늘릴 때 세로 합을 다시 셉니다.
  세로보다 **가로가 먼저 터집니다.** 한 줄에 세 항목을 늘어놓을 때는 `flex-wrap`을 겁니다.
- 여백 좌우 64 / 상 48 / 하 40. 표지만 예외입니다. 헤더 하단 2px 잉크선, 푸터 상단 1px 룰.
- **카드에는 반드시 `1px solid #E4E2DB` 테두리를 넣습니다.** 카드 `#FFFFFF`와 바탕 `#FBFAF7`의 명도 차가 2%뿐이라
  빔과 흑백 인쇄에서 경계가 사라집니다.
- **4px 좌측 룰은 경고 박스 전용.** 다른 강조는 3px이거나 배경 `#EEF0EA`를 씁니다.
- 타입은 **30 / 22 / 19 / 16 / 14 / 12** 여섯 단만 씁니다. 카드 제목은 19 / 600으로 통일합니다.
- 서체 IBM Plex Sans KR, 경로·코드는 IBM Plex Mono. **Inter·Roboto·Arial 금지.**
  대체 스택에 Arial이 들어오지 않도록 `Apple SD Gothic Neo`와 `Noto Sans KR`을 앞에 둡니다.
- 꼬리표 네 기호는 **선 아이콘**으로 그립니다. 이모지는 인쇄·확대에서 깨지고 색을 못 바꿉니다.
  사람만 `#9A2C2C` · AI 초안 `#1C3F94` · AI 반복 `#0F6B4F` · 밖에서 가져옴 `#6B6660`.
  어두운 바 위에서는 사람만을 `#E88B8B`로 씁니다. **네 이름은 과정 문서와 같은 표기를 씁니다.**
- 용어를 섞지 않습니다. 파일은 **지시문 파일**, 도구의 입력칸은 **지침란**, 붙여넣는 내용은 **지시문**입니다.
  `프롬프트`는 덱에서 쓰지 않습니다.
- **푸터에 제작 메모를 쓰지 않습니다.** 관객이 그대로 봅니다. 그런 문구는 `canvas.json`의 메모로 갑니다.
- **슬라이드에 들어가는 수치는 각 모듈 `04_answer/` 기준본에서만** 가져옵니다. 임의로 바꾸면 강사가 참가자 결과를 판정할 수 없습니다.
- 삼성 블루는 자리표시 토큰입니다. `Components.dc.html`의 토큰 값만 바꾸면 전체가 따라갑니다.
- 시간 막대처럼 **비율이 정보인 도식은 `flex: N 0 0`** 으로 그립니다. `flex-grow`만 쓰면 라벨 길이가 폭에 더해져
  30분짜리가 20분짜리와 같은 크기로 나옵니다.
