## ✂ 여기서부터 복사

단계 ①에서 추린 후보 모델로 3안을 만들어줘.
고객이 선택할 수 있게 주는 거라, 세 개가 서로 뭐가 다른지 한눈에 보여야 해.

1안은 요구조건을 **전부 충족**하는 안이야.
2안도 요구조건은 충족하되 **한 급 낮은** 안이고.
3안은 **요구조건 일부를 포기한 최저가안**인데, 무엇을 포기했는지 반드시 적어줘. 포기한 걸 안 적으면 고객이 그냥 싼 안인 줄 알고 고르게 돼.

각 안마다 구역별로 모델·수량·단가·총액을 내고 **예산 대비 비율**도 같이 적어줘.
그다음 3안 상호 비교표를 만들고, 1안 모델의 시장가격 비교표도 만들어줘. 가이드공급가와 온라인가, 경쟁사 가격을 나란히 놓는 거야.
**경쟁사가 더 싼 줄에는 요구조건 중 무엇이 미달인지를 같은 줄에 적어줘.** 싸다는 사실만 보이면 그 표는 우리한테 불리하게만 읽혀.

마지막으로 지침 ⑥번 양식의 HTML 코드 한 덩어리로 출력해줘. 설명 문장은 코드 밖에 쓰지 마.
