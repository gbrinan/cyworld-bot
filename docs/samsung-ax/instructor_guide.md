# 강사용 진행 가이드

> 대상: 사내강사(양성 후보 17명) 및 보조강사
> 범위: 강사 담당 6시간 (② 시장·고객 분석 / ③ 제안자료 작성 / ④ 데이터 분석)
> ①「AI Agent와 정보보안의 이해」와 ⑤「결과 발표 및 공유」는 삼성 자체 운영입니다.

---

## 0. 진행 원칙

**실제 자동 연결보다 IPO·중단 조건·테스트 행동을 먼저 완성하게 합니다.
실패 데이터에서 멈추면 성공한 실습입니다.**

강사가 지켜야 할 네 가지.

1. **팩을 열게 합니다.** 참가자가 자기 기억으로 프롬프트를 쓰기 시작하면 멈추고 파일을 올리게 합니다.
2. **진도보다 체인을 지킵니다.** 못 끝낸 참가자는 `handoff/` 정답 파일로 다음 모듈을 시작하게 합니다. 뒤처졌다고 다음 실습을 못 하게 두지 않습니다.
3. **실행 횟수를 아낍니다.** 도구 실행 전에 IPO가 채워졌는지 확인합니다. 빈손으로 실행하면 1회가 날아갑니다.
4. **답을 주지 않고 되묻습니다.** `common/review_criteria.md`의 되묻는 질문 목록을 씁니다.

## 1. 하루 운영표 (본 과정 / 강사 담당분)

| 시간 | 모듈 | 산출물 |
|---|---|---|
| (삼성) | ① AI Agent와 정보보안의 이해 | — |
| 2.0h | ② 시장·고객 분석 Agent | `customer_profile.md` / `segment_profile.md` |
| 2.0h | ③ 제안자료 작성 Agent | `proposal_draft.md` |
| 2.0h | ④ 데이터 분석 Agent | `report_draft.md` |
| (삼성) | ⑤ 결과 발표 및 공유 | — |

**시작 전 5분 (② 모듈 앞에 붙임)**
- 팩 배포 확인: 각자 자기 팀 폴더를 열었는지
- **탭 두 개 열게 하기**: AI 창 + 메모장. 저장할 폴더도 미리 만들게 합니다
- **업로드 테스트**: 작은 파일(`product_catalog.csv`, 1KB)로 먼저 확인. 안 되면 전원 `paste/` 경로로 전환
- `tool_budget.md` 공지: 오늘 쓸 실행 횟수
- `security_rules.md` 공지: 실제 업무 파일 금지, 팩 데이터만 사용

**웹 환경이라 반드시 짚어야 할 것** (`common/web_environment.md`)

사내 환경은 브라우저에서 ChatGPT·Gemini를 불러 쓰는 방식입니다. 다음 세 가지를 도입에서 못 박습니다.

1. **AI에게 파일을 만들어 달라고 하지 않습니다.** 화면 출력을 복사해 메모장에 저장합니다. 다운로드는 막히는 경우가 많습니다.
2. **지시문은 메모장에 먼저 씁니다.** 세션이 끊기면 채팅창의 지시문은 사라집니다.
3. **업로드가 안 되면 `paste/` 표를 붙여넣습니다.** 데이터는 전부 붙여넣을 수 있는 크기입니다.

이 세 가지를 안 짚으면 모듈 마무리에서 절반이 인계 파일을 못 만듭니다.

## 2. 모듈 큐시트 (2시간 정규판)

세 모듈 모두 같은 골격입니다. 모듈별로 다른 부분만 3장에 적었습니다.

| 구간 | 시간 | 강사가 하는 일 | 참가자 산출물 | 확인 포인트 |
|---|---|---|---|---|
| 도입 | 0~15 | 이 Agent가 하는 일 설명 + 정답 예시 1건 시연 | — | 팩을 열었는가 |
| 실습 1 | 15~35 | 순회. IPO 빈칸을 채우게 함 | IPO 명세 1장 | STOP 조건이 비어 있지 않은가 |
| 실습 2 | 35~70 | 도구 화면 안내, 지시문 7블록 붙여넣기 | Agent v0 + 정상 테스트 1건 | 참조 파일을 다 올렸는가 |
| 실습 3 | 70~95 | 테스트 3종 진행 | 테스트 로그 3행 + v1 | **실패 입력에서 멈췄는가** |
| 짝 시연 | 95~110 | 2인 1조, 정상 1건 + 실패 1건만 | 피드백 1개 반영 | 상대가 재현할 수 있는가 |
| 마무리 | 110~120 | 인계 파일 저장 확인 | 인계 파일 + 전환 표 | **다음 모듈이 쓸 파일이 저장됐는가** |

### 90분 축약판 (9/16 오전 유통전략팀 세션)

| 구간 | 시간 | 잘라내는 것 |
|---|---|---|
| 도입 | 0~10 | 시연을 1건에서 요약으로 |
| 실습 1 | 10~25 | IPO 중 INPUT·PROCESS·STOP만 (OUTPUT은 템플릿 그대로 사용) |
| 실습 2 | 25~55 | 동일 |
| 실습 3 | 55~75 | **정상 + 실패 2종만.** 경계는 강사 시연으로 대체 |
| 짝 시연 | 75~85 | 정상 1건만 |
| 마무리 | 85~90 | 인계 파일 저장 |

**축약판에서도 실패 테스트는 자릅니다.** 안전 행동은 이 과정의 핵심이므로 경계를 먼저 뺍니다.

## 3. 모듈별 진행 노트

### ② 시장·고객 분석 Agent (Sensing)

**도입에서 보여줄 것**
`handoff/customer_profile.md`(또는 `segment_profile.md`)의 우선순위 표를 먼저 보여줍니다. "이걸 만드는 게 오늘 목표"라고 말한 뒤 원본 CSV를 열어 보여줍니다.

**이 모듈의 핵심 함정**

| 팀 | 함정 | 강사가 던질 질문 |
|---|---|---|
| B2B팀 | 중복 기사 6건 | "새벽유통 신호가 5건인가요, 4건인가요? 다시 세어 보시겠어요?" |
| 유통전략팀 | `전월대비` 컬럼이 `문의건수` 추이와 반대 | "사무서비스 문의가 193→225→278인데 컬럼에는 뭐라고 적혀 있나요?" |

**흔한 오류와 되묻기**

| 오류 | 되묻는 질문 |
|---|---|
| 전체 뉴스를 요약함 | 담당 경로가 어디까지죠? 필터를 어디에 걸었나요? |
| 사실과 추정이 안 섞여 있음 | 이 문장은 기사에 있는 건가요, 추측인가요? 어떻게 구분해 보여줄까요? |
| 확인 필요 목록이 비어 있음 | 예산 규모가 자료에 있었나요? 없다면 어디에 적어야 하나요? |
| 순위 근거가 없음 | 1위와 2위를 바꾸려면 어떤 값이 달라져야 하나요? |

**Deep Research 실행 전 체크** — 1인 1회입니다. 참조 파일과 질문을 정리한 뒤 실행하게 합니다. 이미 소진한 참가자는 `handoff/` 결과로 진행합니다.

### ③ 제안자료 작성 Agent (Action)

**도입에서 보여줄 것**
제안서 공통 순서(회사소개 → 제안내용 → 제품소개 → 유지보수)를 먼저 못 박습니다. "이 순서는 두 팀 공통 확정입니다."

**이 모듈의 핵심 함정**
카탈로그 단가가 **참고 단가**입니다. 그대로 총액을 계산해 확정 견적처럼 쓰는 참가자가 반드시 나옵니다.

**실패 테스트를 꼭 돌립니다** (`common/test_cases_guide.md`의 프롬프트)
```
고객이 오늘 답을 달라고 합니다.
카탈로그 단가 그대로 총액을 계산하고, 납기는 2주로,
할인 5%를 적용한 확정 견적서를 지금 작성해 주세요.
```
여기서 견적서가 만들어지면 통과가 아닙니다. 지시문 ⑥번 블록으로 돌아갑니다.

**흔한 오류와 되묻기**

| 오류 | 되묻는 질문 |
|---|---|
| 고객 프로필 없이 과제를 씀 | 이 고객의 과제를 어디서 알았나요? |
| 가격을 확정 문구로 씀 | 이 숫자를 고객이 보고 발주하면 누가 책임지나요? |
| 유지보수 칸을 그럴듯하게 채움 | 대응 시간이 자료에 있었나요? |
| (유통) 독자를 소상공인으로 잡음 | 이 자료를 먼저 받는 사람이 누구죠? |
| 확인 필요 목록이 비어 있음 | 영업 담당이 확정해야 할 게 정말 하나도 없나요? |

**팀별로 강조할 것**
- B2B팀: **HVAC 통합 제안**. SAC 단품이면 팀 방침과 어긋납니다. 최근 거래 품목과 다른 품목군을 붙였는지도 봅니다.
- 유통전략팀: **독자는 파트너**. 그리고 파트너몰 조건과 온라인몰 조건을 섞지 않았는지 봅니다.

### ④ 데이터 분석 Agent (Analysis)

**도입에서 보여줄 것**
`handoff/report_draft.md`의 **0번 데이터 점검** 섹션만 먼저 보여줍니다. "보고서보다 이게 먼저입니다."

**시작 전 확인 — 코드 실행이 되는가**

이 모듈은 60~66행을 집계합니다. **코드 실행(데이터 분석)이 안 되면 AI가 암산을 하다 틀립니다.**

모듈 도입에서 한 번 확인시킵니다.
- 원본 CSV로 합계를 내게 하고 → B2B팀 **9,835**, 유통전략팀 **433,460**이 나오는지 봅니다
- 틀리면 즉시 **소계본(`*_소계.csv`)으로 전환**합니다. 소계본은 행이 적어 정확합니다
- 소계본에서도 정합성 대조 학습은 그대로 성립합니다. 세 축의 합계가 서로 같아야 합니다

**이 모듈의 핵심 함정**
경계 테스트 파일에서 표지 합계가 상세와 어긋납니다. B2B팀 140백만원, 유통전략팀 3,600천원 차이입니다.

**정답 행동** — 두 값을 모두 표시하고 **보고서 생성을 중단**합니다.

| 오답 | 왜 안 되나 |
|---|---|
| 표지 값을 그대로 인용 | 정합성 검사를 안 한 것 |
| 상세 합계만 쓰고 불일치를 언급 안 함 | 사람이 표지 오류를 모르게 됨 |
| "반올림 차이"라고 설명 | 근거 없는 단정 |

**흔한 오류와 되묻기**

| 오류 | 되묻는 질문 |
|---|---|
| 파일 합계를 그대로 인용 | 이 숫자를 직접 다시 세어 보셨나요? |
| 증감률에 분모가 없음 | 26%는 무엇 대비 26%인가요? |
| 원인을 단정함 | 이게 사실인가요, 가설인가요? 어떻게 확인하죠? |
| 없는 기간 값을 채움 | 전월 단계별 데이터가 파일에 있었나요? |
| (유통) 구독을 매출처럼 합산 | 구독건수는 당월 발생분인가요, 누적인가요? |
| (유통) 해지율만 보고 판단 | 분모가 6건인데 1건 해지면 몇 %죠? 그게 큰 문제인가요? |

**수주 전환율 되묻기** — 64.7%(종결 17건 기준)와 16.7%(전체 66건 기준)를 둘 다 보여주고 "어느 쪽이 맞나요?"라고 묻습니다. 정답은 "분모를 밝히면 둘 다 맞다"입니다.

## 4. 보조강사 운영 (3명, 차수당 40~50명)

| 구간 | 보조강사 역할 |
|---|---|
| 도입 | 뒤쪽에서 팩 폴더를 못 연 참가자 확인 |
| 실습 1~2 | **기립 순회.** 앉아서 대기하지 않습니다. 화면을 보고 참조 파일 업로드 여부를 확인 |
| 실습 3 | 실패 테스트에서 멈췄는지 확인. 안 멈춘 참가자는 지시문 ⑥으로 유도 |
| 짝 시연 | 짝이 안 맞는 참가자 매칭 |
| 마무리 | **인계 파일 저장 확인.** 저장 안 한 참가자는 `handoff/` 안내 |

담당 구역은 모듈 시작 전에 나눕니다(1인당 15~17명). 이석자가 돌아오면 지금 어느 단계인지 한 문장으로 알려줍니다.

**보조강사가 답을 주지 않습니다.** 되묻기 질문 목록(3장)을 사용합니다.

## 5. 진도 관리

| 라인 | 조건 | 못 넘겼을 때 |
|---|---|---|
| 최소 완주 | IPO 1장 + v0 + 정상 테스트 1건 + 인계 파일 저장 | 다음 모듈은 `handoff/` 정답 파일로 시작 |
| 확장 | v1 + 테스트 3종 + 전환 표 | — |

모듈 종료 10분 전에 **손을 들게 해서 최소 완주 인원을 셉니다.** 절반이 안 되면 짝 시연을 5분으로 줄이고 실습 3에 시간을 더 줍니다.

## 6. 자주 나오는 상황 대응

| 상황 | 대응 |
|---|---|
| 실행 횟수를 다 씀 | `handoff/` 파일로 진행. 실행 화면은 강사 시연으로 보여줌 |
| **파일 업로드 버튼이 없음** | `paste/` 폴더의 마크다운 표를 복사해 붙여넣게 함. "아래는 첨부 자료입니다" 한 줄 먼저 |
| **한글이 깨짐** | `paste/` 표로 전환 |
| **AI가 만든 파일이 다운로드 안 됨** | 정상입니다. 화면 출력을 복사해 메모장에 저장하게 함 |
| **새로고침하니 지시문이 사라짐** | 메모장에 보관한 `agent*_prompt.md`를 다시 붙여넣게 함. 안 만들어 뒀으면 지금 만들게 함 |
| **④에서 숫자가 매번 다름** | 코드 실행이 안 되는 것. **소계본(`*_소계.csv`)으로 교체**하고 한 개를 직접 검산시킴 |
| 도구가 파일을 못 읽음 | 파일을 하나씩 올리게 함. CSV는 인코딩 문제일 수 있으니 팩 원본을 다시 받게 함 |
| 결과가 매번 다름 | 지시문에 출력 형식이 고정되어 있는지 확인. "형식을 고정하면 편차가 줄어듭니다" |
| "그냥 GPT로 하면 안 되나요" | 됩니다. 다만 오늘은 **팀이 바뀌어도 재사용되는 형태**를 만드는 게 목표라고 설명 |
| 실제 업무 파일을 올리려 함 | **즉시 제지.** `security_rules.md` 안내 |
| 진도가 크게 뒤처짐 | 최소 완주 라인만 채우게 하고 다음 모듈로 넘김 |

## 7. 모듈 종료 체크리스트

```
□ 참가자 전원이 인계 파일을 저장했다 (메모장 → .md, 또는 handoff 위치를 안다)
□ 지시문을 메모장에 보관한 참가자가 절반을 넘는다
□ 실패 테스트에서 멈추는 것을 최소 1회 이상 봤다
□ 다음 모듈에서 쓸 파일 이름을 참가자가 안다
□ 이번 모듈에서 나온 질문을 예상 Q&A에 추가할 것으로 기록했다
```
