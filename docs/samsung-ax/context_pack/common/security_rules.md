# 보안 규칙 — 실습 중 지키는 것

본 과정 ① 「AI Agent와 정보보안의 이해」(삼성 자체 운영)와 정합을 맞춘 실습용 규칙입니다. 사내 정식 가이드가 우선하며, 이 문서는 실습 시간에 적용하는 최소 규칙입니다.

## 절대 업로드하지 않습니다

| 구분 | 예 |
|---|---|
| 개인정보 | 고객 담당자 실명·직급·휴대폰·이메일, 임직원 사번 |
| 계약·거래 조건 | 실제 계약 단가, 할인율, 결제 조건, 계약서 원문 |
| 미공개 경영 정보 | 미발표 신제품 사양·출시일, 미공개 실적, 내부 전략 문서 |
| 인증 정보 | 사내 시스템 계정·비밀번호, API 키, VDI 접속 정보 |
| 파트너 비밀 | 파트너사 원가, 파트너 계약 조건 |

## 실습에서는 이렇게 대체합니다

| 실제 | 실습 대체 |
|---|---|
| 고객사명 | `가온건설`, `한빛전자` 등 팩의 가상 고객사 |
| 담당자 | `담당자 A`, `구매팀장 B` |
| 계약 단가 | 팩의 가상 단가 (`product_catalog.csv`) |
| 실적 데이터 | 팩의 가상 실적 (`*_sales.xlsx`) |

**본 과정에서는 팩의 더미 데이터만 씁니다.** 내 실제 업무 파일을 올리지 않습니다. 교육 후 현업 적용 시에는 사내 가이드에 따라 가명화·정제한 사본만 사용합니다.

## Agent 지시문에 반드시 넣는 문장

```
입력에 실명·연락처·사번·계약 단가가 포함되면
결과물을 만들지 말고 가명화를 요청한 뒤 중단한다.
```

## 실습 중 실수했을 때

1. 대화를 계속 이어가지 말고 즉시 중단합니다.
2. 해당 대화·업로드 파일을 삭제합니다.
3. 강사·보조강사에게 알립니다.
4. 사내 정보보안 절차에 따라 보고합니다.

## 결과물 반출

- 실습 산출물(제안서 초안, 보고서 초안)은 가상 데이터 기반이므로 개인 학습용 보관은 가능합니다.
- 다만 **가상 데이터임을 파일명에 표시**합니다: `[실습]제안서초안_가온건설_가상.md`
